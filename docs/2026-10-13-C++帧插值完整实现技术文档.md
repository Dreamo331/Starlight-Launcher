# Starlight 帧插值（Frame Interpolation）完整实现技术文档

> **版本**：r2（已修复首版 5 个 P0 缺陷，详见下方修订记录）
> **文档定位**：从零实现一套 C++ 帧插值宿主进程，并与当前 Java/JavaFX 启动器对接。
> **不含现有代码内容**：本文所有代码段均为新增文件，不复制、不修改任何现有源文件。
> **兼容性**：所有 Java 代码只调用现有公开 API（`LauncherContext`、`PageKit`、`AppIcons`、`AppDirs`、`UiService`、`Gson`），可直接编译进现有工程。

### 1.2 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| **进程隔离** | 独立 exe，非 JNI 库 | 图形栈崩溃隔离；避免破坏 Gluon substrate 单 exe 打包 |
| **捕获方式** | WGC 优先，DXGI DD 兜底 | WGC 支持窗口级捕获、多消费者、不含光标；DD 兼容老系统 |
| **传输** | TCP loopback + JSON Lines | Java 无原生命名管道双向支持；TCP 调试友好 |
| **HWND 获取** | C++ 侧 `EnumWindows` 按 PID 找 | Java 侧零原生代码，避免引入 JNA |
| **输入处理** | `WM_NCHITTEST → HTTRANSPARENT` | 窗口天然不接收输入，事件直达下层游戏窗口，无需转发器 |
| **渲染模式** | 强制窗口化/无边框 | 独占全屏捕获后争抢显示模式，无法可靠支持 |
| **倍率上限** | 固定 2x | 8x 单帧预算 2ms，任何算法必然糊；见 §8 |

### 1.3 为什么不注入游戏

现有工程已有成熟 javaagent 体系（`AuthlibInjectorSupport`、`cape-url-patch-agent`），但图形 Hook 与字节码改写风险量级不同：

- `glfwSwapBuffers` Hook 需对 1.12/1.16/1.20 × Forge/Fabric/OptiFine/Iris 组合逐一适配；
- OptiFine 全屏优化与 Sodium 的交换链逻辑冲突史很长；
- 注入崩溃时用户无法区分是游戏问题还是启动器问题，排障成本极高。

**外部捕获天然规避以上全部问题**，代价是必须窗口化。

## 3. IPC 协议规范

### 3.1 传输层

| 项 | 值 |
|---|---|
| 协议 | TCP |
| 地址 | `127.0.0.1` |
| 端口 | 由 host 启动后打印到 stdout 第一行 `PORT <n>` |
| 编码 | UTF-8 |
| 帧格式 | 单行 JSON，`\n` 结尾 |
| 心跳 | 启动器每 3000ms 发 `{"cmd":"ping","seq":N}`，host 回 `{"evt":"pong","seq":N}` |

### 3.2 启动参数

```
framegen-host.exe \
  --pid <gamePd>            # 必填：Minecraft javaw.exe 的 PID
  --quality <0|1|2>         # 0=blend 1=blockmatch 2=neural(未实现,降级1)
  --target <fps>            # 目标输出帧率，默认 120
  --log <path>              # 日志文件
  --no-capture-cursor       # 默认开启
```

### 3.3 命令（Launcher → Host）

```json
{"cmd":"start"}
{"cmd":"stop"}
{"cmd":"config","quality":1,"target":120}
{"cmd":"ping","seq":12}
{"cmd":"quit"}
```

### 3.4 事件（Host → Launcher）

```json
{"evt":"hello","version":"0.1.0","capture":"wgc","width":1920,"height":1080,"hdr":false}
{"evt":"status","running":true,"presenting":true,"captureFrames":120,"presentFrames":240,"shownFrames":118,"dropFrames":3,"interpMs":2.7,"quality":1,"displayHz":144,"targetHz":120,"rebuildCount":0,"closed":false}
{"evt":"error","code":"WINDOW_GONE","message":"目标窗口已关闭"}
{"evt":"pong","seq":12}
{"evt":"bye","reason":"pid-exited"}
```

### 3.5 状态字段语义

| 字段 | 含义 |
|---|---|
| `running` | 是否正在做插值（竞技模式下为 `false`，但画面仍在呈现） |
| `presenting` | 是否正在呈现（用于区分「直通」与「未启动」） |
| `captureFrames` | 累计捕获帧数（绝对计数，UI 自行差分算 fps） |
| `presentFrames` | 累计提交呈现次数（**不等于**屏幕显示帧数，60Hz 屏会丢） |
| `shownFrames` | **上一秒实际显示到屏幕的帧数**，遥测应以它为准 |
| `displayHz` | 呈现窗口所在显示器的实际刷新率 |
| `targetHz` | host 实际采用的输出节奏（已按 `displayHz` 钳制） |
| `interpMs` | 每帧插值耗时（毫秒） |
| `dropFrames` | 累计丢弃帧数（插值失败或捕获端跟不上） |
| `rebuildCount` | 纹理/交换链重建次数，持续增长说明尺寸在抖动 |
| `closed` | 目标窗口是否已关闭 |

> **r2 修订**：早期版本用 `captureFps` / `presentFps` 直接上报浮点帧率，
> 但「提交两次 Present」不等于「显示两帧」——60Hz 显示器上第二次
> `Present(1,0)` 会阻塞到下一个 vblank，实际仍只有 60fps。
> 现改为上报绝对计数 + 真实显示帧数，由接收方差分计算，并强制上报
> `displayHz` / `targetHz` 让 UI 能如实显示「钳制后」的节奏。

### 3.6 错误码

| code | 含义 | 是否可恢复 |
|---|---|---|
| `WINDOW_GONE` | 目标窗口已销毁 | 否，需等游戏重新启动 |
| `CAPTURE_LOST` | 捕获源丢失（显示器拔出/模式切换） | 可尝试重建捕获 |
| `DEVICE_LOST` | D3D 设备移除（驱动更新/TDR） | 需重启 host |
| `UNSUPPORTED` | 系统不支持 WGC，或权限层级不一致 | 否，需用户处理 |

```cpp
namespace sfg {

// 全局共享的 D3D11 设备上下文。
// 捕获、插值、呈现三处共用同一个 device，避免跨设备拷贝纹理。
class D3DContext {
public:
    bool Init();
    void Shutdown();

    ID3D11Device*           Device()           const { return device_.Get(); }
    ID3D11DeviceContext*    Context()          const { return context_.Get(); }
    IDXGISwapChain1*        SwapChain()        const { return swapChain_.Get(); }
    ID3D11Device1*          Device1()          const { return device1_.Get(); }
    ID3D11DeviceContext1*   Context1()         const { return context1_.Get(); }

    // 创建（或重建）与指定 HWND 绑定的交换链
    bool CreateSwapChain(HWND hwnd, int width, int height);
    void DestroySwapChain();

    // 设备丢失检测与恢复
    bool CheckDeviceLost();
    bool Recreate();

private:
    bool CreateDevice();

    ComPtr<ID3D11Device>            device_;
    ComPtr<ID3D11DeviceContext>     context_;
    ComPtr<ID3D11Device1>           device1_;
    ComPtr<ID3D11DeviceContext1>    context1_;
    ComPtr<IDXGISwapChain1>         swapChain_;
    ComPtr<IDXGIFactory2>           factory_;
    ComPtr<ID3D11RenderTargetView>  backBufferRtv_;

    int width_  = 0;
    int height_ = 0;
```

#### src/D3DContext.cpp

```cpp
#include "D3DContext.h"
#include <d3d11_1.h>

namespace sfg {

bool D3DContext::Init() {
    if (!CreateDevice()) {
        LogError("D3D11 device creation failed");
        return false;
    }
    LogInfo("D3D11 device created: %s",
            device_.As(&device1_) ? "feature-level 11.1" : "feature-level 11.0");
    return true;
}

bool D3DContext::CreateDevice() {
    UINT flags = D3D11_CREATE_DEVICE_BGRA_SUPPORT;
#ifdef _DEBUG
    flags |= D3D11_CREATE_DEVICE_DEBUG;
#endif

    D3D_FEATURE_LEVEL levels[] = {
        D3D_FEATURE_LEVEL_11_1,
        D3D_FEATURE_LEVEL_11_0,
        D3D_FEATURE_LEVEL_10_1,
        D3D_FEATURE_LEVEL_10_0,
    };
    D3D_FEATURE_LEVEL obtained = D3D_FEATURE_LEVEL_11_0;

    HRESULT hr = D3D11CreateDevice(
        nullptr, D3D_DRIVER_TYPE_HARDWARE, nullptr, flags,
        levels, _countof(levels), D3D11_SDK_VERSION,
        &device_, &obtained, &context_);

    if (FAILED(hr)) {
        // 11_1 在 Win7 上不被识别，降级重试
        LogInfo("D3D11CreateDevice failed (0x%08X), retrying with WARP", hr);
        hr = D3D11CreateDevice(
            nullptr, D3D_DRIVER_TYPE_WARP, nullptr, flags,
            levels, _countof(levels), D3D11_SDK_VERSION,
            &device_, &obtained, &context_);
        if (FAILED(hr)) {
            LogError("WARP device also failed: 0x%08X", hr);
            return false;
        }
    }

    // 获取 Device1 / Context1（可选）
    device_.As(&device1_);
    context_.As(&context1_);

    // DXGI factory
    ComPtr<IDXGIDevice> dxgiDevice;
    if (SUCCEEDED(device_.As(&dxgiDevice))) {
        ComPtr<IDXGIAdapter> adapter;
        if (SUCCEEDED(dxgiDevice->GetAdapter(&adapter))) {
            ComPtr<IDXGIFactory2> factory;
            if (SUCCEEDED(adapter->GetParent(IID_PPV_ARGS(&factory)))) {
                factory_ = factory;
            }
        }
    }
    return true;
}

bool D3DContext::CreateSwapChain(HWND hwnd, int width, int height) {
    if (!factory_ || !hwnd || width <= 0 || height <= 0) {
        return false;
    }
    DestroySwapChain();
    hwnd_   = hwnd;
    width_  = width;
    height_ = height;

    DXGI_SWAP_CHAIN_DESC1 desc{};
    desc.Width            = static_cast<UINT>(width);
    desc.Height           = static_cast<UINT>(height);
    desc.Format           = DXGI_FORMAT_B8G8R8A8_UNORM;
    desc.Stereo           = FALSE;
    desc.SampleDesc.Count = 1;
    desc.BufferUsage      = DXGI_USAGE_RENDER_TARGET_OUTPUT;
    desc.BufferCount      = 2;
    desc.Scaling          = DXGI_SCALING_STRETCH;
    desc.SwapEffect       = DXGI_SWAP_EFFECT_FLIP_DISCARD;
    desc.AlphaMode        = DXGI_ALPHA_MODE_IGNORE;
    desc.Flags            = 0;

    HRESULT hr = factory_->CreateSwapChainForHwnd(
        device_.Get(), hwnd, &desc, nullptr, nullptr, &swapChain_);
    if (FAILED(hr)) {
        LogError("CreateSwapChainForHwnd failed: 0x%08X", hr);
        return false;
    }

    factory_->MakeWindowAssociation(hwnd, DXGI_MWA_NO_ALT_ENTER);

    ComPtr<ID3D11Texture2D> backBuffer;
    if (FAILED(swapChain_->GetBuffer(0, IID_PPV_ARGS(&backBuffer)))) {
        LogError("GetBuffer failed");
        return false;
    }
    if (FAILED(device_->CreateRenderTargetView(backBuffer.Get(), nullptr, &backBufferRtv_))) {
        LogError("CreateRenderTargetView failed");
        return false;
    }
    return true;
}

void D3DContext::DestroySwapChain() {
    backBufferRtv_.Reset();
    swapChain_.Reset();
}

bool D3DContext::CheckDeviceLost() {

    HRESULT hr = device_->GetDeviceRemovedReason();
    return FAILED(hr);
}

bool D3DContext::Recreate() {
    Shutdown();
    return Init();
}

void D3DContext::Shutdown() {

    factory_.Reset();
    context1_.Reset();
    device1_.Reset();

    device_.Reset();
```

```cpp
bool CaptureWgc::Init(HWND target, ID3D11Device* device, FrameCallback cb) {
    try {
        winrt::init_apartment(winrt::apartment_type::multi_threaded);
    } catch (...) {
        // 已初始化则忽略
    }

    device_ = device;
    device.As(&context_);
    cb_ = std::move(cb);

    try {
        // 1) 把 DXGI device 包成 WinRT IDirect3DDevice
        ComPtr<IDXGIDevice> dxgiDevice;
        check_hresult(device_.As(&dxgiDevice));

        ComPtr<IInspectable> inspectable;
        check_hresult(CreateDirect3D11DeviceFromDXGIDevice(
            dxgiDevice.Get(), inspectable.GetAddressOf()));
        winrtDevice_ = inspectable.as<wgdx::Direct3D11::IDirect3DDevice>();

        // 2) 窗口 → GraphicsCaptureItem
        item_ = ItemFromHwnd(target);

        // 3) 建帧池
        auto size = item_.Size();
        if (!EnsureFramePool(item_, size.Width, size.Height)) {
            return false;
        }

        // 4) 建会话
        session_ = framePool_.CreateCaptureSession(item_);

        // 光标不参与捕获（否则插值会让准心轻微重影）
        session_.IsCursorCaptureEnabled(false);

        // 尝试关闭黄框
        TryDisableBorder(true);

        session_.StartCapture();
        LogInfo("[WGC] capture started: %dx%d", size.Width, size.Height);
        return true;
    }
    catch (winrt::hresult_error const& e) {
        LogError("[WGC] init failed: 0x%08X %ls",
                 static_cast<unsigned>(e.code()), e.message().c_str());
        return false;
    }
    catch (...) {
        LogError("[WGC] init failed with unknown error");
        return false;
    }
}

bool CaptureWgc::EnsureFramePool(const wgc::GraphicsCaptureItem& item, int w, int h) {
    if (w <= 0 || h <= 0) return false;

    // 每 2 帧更新一次尺寸变化（窗口缩放）
    if (framePool_) {
        framePool_.Recreate(
            winrtDevice_,
            wgdx::DirectXPixelFormat::B8G8R8A8UIntNormalized,
            2,
            { w, h });
        return true;
    }

    framePool_ = wgc::Direct3D11CaptureFramePool::CreateFreeThreaded(
        winrtDevice_,
        wgdx::DirectXPixelFormat::B8G8R8A8UIntNormalized,
        2,
        { w, h });

    geom_.width  = w;
    geom_.height = h;
    geom_.stride = w * 4;

    frameToken_ = framePool_.FrameArrived(
        [this](wgc::Direct3D11CaptureFramePool const& sender,
               winrt::Windows::Foundation::IInspectable const&) {
            OnFrameArrived(sender, {});
        });

    return framePool_ != nullptr;
}

void CaptureWgc::OnFrameArrived(wgc::Direct3D11CaptureFramePool const& sender,
                                winrt::Windows::Foundation::IInspectable const&) {
    auto frame = sender.TryGetNextFrame();
    if (!frame) return;

    try {
        auto size = frame.ContentSize();
        if (size.Width > 0 && size.Height > 0) {
            std::lock_guard<std::mutex> lock(mutex_);
            if (size.Width != geom_.width || size.Height != geom_.height) {
                LogInfo("[WGC] size changed: %dx%d -> %dx%d",
                        geom_.width, geom_.height, size.Width, size.Height);
                geom_.width  = size.Width;
                geom_.height = size.Height;
                geom_.stride = size.Width * 4;
                // 尺寸变化：重建帧池
                sender.Recreate(winrtDevice_,
                                wgdx::DirectXPixelFormat::B8G8R8A8UIntNormalized,
                                2, { size.Width, size.Height });
            }
        }

        auto tex = GetTextureFromSurface(frame.Surface());
        int64_t qpc = NowQpc();
        if (cb_ && tex) {
            cb_(tex.Get(), qpc);
        }
    }
    catch (winrt::hresult_error const& e) {
        LogError("[WGC] frame error: 0x%08X", static_cast<unsigned>(e.code()));
        closed_.store(true);
    }

    frame.Close();
}

void CaptureWgc::TryDisableBorder(bool disable) {
    try {
        session_.IsBorderRequired(!disable);
        LogInfo("[WGC] border %s", disable ? "disabled" : "enabled");
    }
    catch (...) {
        // Windows 11 之前不支持，忽略
        LogInfo("[WGC] IsBorderRequired unsupported on this OS build");
    }
}

        if (session_) {
            session_.Close();
            session_ = nullptr;
        }
        if (framePool_) {
            framePool_.FrameArrived(frameToken_);
            framePool_.Close();
            framePool_ = nullptr;
        }
        item_ = nullptr;
        winrtDevice_ = nullptr;
    }
    catch (...) {
    }
    closed_.store(true);
    LogInfo("[WGC] shutdown");
}
```

```cpp
bool CaptureDxgi::Init(HWND target, ID3D11Device* device, FrameCallback cb) {
    target_ = target;
    device_ = device;
    device.As(&context_);
    cb_ = std::move(cb);

    if (!target_ || !IsWindowAlive(target_)) {
        LogError("[DXGI] invalid target window");
        return false;
    }

    GetWindowRect(target_, &crop_);
    geom_.width  = crop_.right - crop_.left;
    geom_.height = crop_.bottom - crop_.top;
    geom_.stride = geom_.width * 4;
    if (!geom_.valid()) {
        LogError("[DXGI] invalid geometry");
        return false;
    }

    ComPtr<IDXGIDevice> dxgiDevice;
    if (FAILED(device_.As(&dxgiDevice))) return false;

    ComPtr<IDXGIAdapter> adapter;
    if (FAILED(dxgiDevice->GetAdapter(&adapter))) return false;

    // 找到包含目标窗口的 output
    ComPtr<IDXGIOutput> output;
    if (FAILED(adapter->EnumOutputs(0, &output))) {
        LogError("[DXGI] EnumOutputs failed");
        return false;
    }
    ComPtr<IDXGIOutput1> output1;
    if (FAILED(output.As(&output1))) {
        LogError("[DXGI] IDXGIOutput1 unavailable");
        return false;
    }
    HRESULT hr = output1->DuplicateOutput(device_.Get(), &duplication_);
    if (FAILED(hr)) {
        LogError("[DXGI] DuplicateOutput failed: 0x%08X", hr);
        return false;
    }

    LogInfo("[DXGI] capture started: %dx%d at (%ld,%ld)",
            geom_.width, geom_.height, crop_.left, crop_.top);
    return true;
}

void CaptureDxgi::Poll() {
    if (!duplication_ || closed_.load()) return;

    DXGI_OUTDUPL_FRAME_INFO info{};
    ComPtr<IDXGIResource> resource;
    HRESULT hr = duplication_->AcquireNextFrame(16, &info, &resource);

    if (hr == DXGI_ERROR_WAIT_TIMEOUT) {
        return; // 无新帧，正常
    }
    if (FAILED(hr)) {
        LogError("[DXGI] AcquireNextFrame failed: 0x%08X", hr);
        if (hr == DXGI_ERROR_ACCESS_LOST) {
            closed_.store(true);
        }
        return;
    }

    ComPtr<ID3D11Texture2D> tex;
    if (SUCCEEDED(resource.As(&tex)) && cb_) {
        cb_(tex.Get(), NowQpc());
    }
    duplication_->ReleaseFrame();
}

void CaptureDxgi::Shutdown() {
    duplication_.Reset();
    staging_.Reset();
    closed_.store(true);
    LogInfo("[DXGI] shutdown");
}
```

#### src/Interpolator.cpp

```cpp
#include "Interpolator.h"
#include <d3dcompiler.h>
#include <vector>

namespace sfg {

const char* QualityName(Quality q) {
    switch (q) {
        case Quality::Blend:      return "blend";
        case Quality::BlockMatch: return "blockmatch";
        case Quality::Neural:     return "neural(downgraded)";
    }
    return "unknown";
}

namespace {

// ------------------------------------------------------------------
// 着色器源码
// ------------------------------------------------------------------

// L0：两帧线性混合。零运动估计，快速平移会有拖影。
constexpr char kBlendHlsl[] = R"(
Texture2D<float4> PrevTex : register(t0);
Texture2D<float4> CurrTex : register(t1);
RWTexture2D<float4> OutTex : register(u0);

[numthreads(16, 16, 1)]
void CSMain(uint3 id : SV_DispatchThreadID)
{
    float4 a = PrevTex.Load(int3(id.xy, 0));
    float4 b = CurrTex.Load(int3(id.xy, 0));
    OutTex[id.xy] = lerp(a, b, 0.5);
}
)";

// L1：块匹配运动估计 + 双向 warp。
// 对每个 8x8 块在 ±SEARCH 范围内搜索最佳匹配，得到前后两帧之间的运动矢量，
// 然后按 0.5 权重分别从两帧采样并混合。
constexpr char kBlockMatchHlsl[] = R"(
Texture2D<float4> PrevTex : register(t0);
Texture2D<float4> CurrTex : register(t1);
RWTexture2D<float4> OutTex : register(u0);

cbuffer Params : register(b0)
{
    uint2 Size;
    int   BlockSize;    // 默认 8
    int   SearchRadius; // 默认 8
    float Blend;        // 默认 0.5
    float _pad0;
    float _pad1;
    float _pad2;
};

static const int BLOCK = 8;

float Luma(float4 c) { return dot(c.rgb, float3(0.299, 0.587, 0.114)); }

// 在一个块上计算 SAD（Sum of Absolute Differences）。
// 越界处理：整块跳过越界像素，按实际有效像素数归一化，避免钳制引入假匹配。
// 若有效像素不足一半，返回一个很大的 SAD，让该候选直接落选。
float BlockSAD(int2 basePos, int2 offset)
{
    float sad = 0.0;
    int   valid = 0;
    [loop]
    for (int y = 0; y < BLOCK; y++)
    {
        [loop]
        for (int x = 0; x < BLOCK; x++)
        {
            int2 p = basePos + int2(x, y);
            int2 q = p + offset;
            // 任一端越界 → 跳过该像素（而不是钳制到边缘）
            if (p.x < 0 || p.y < 0 || p.x >= int(Size.x) || p.y >= int(Size.y)) continue;
            if (q.x < 0 || q.y < 0 || q.x >= int(Size.x) || q.y >= int(Size.y)) continue;
            sad += abs(Luma(PrevTex.Load(int3(p, 0))) - Luma(CurrTex.Load(int3(q, 0))));
            valid++;
        }
    }
    // 有效像素不足一半：判定该候选不可信
    if (valid * 2 < BLOCK * BLOCK) return 1e9;
    return sad / float(valid);
}

[numthreads(8, 8, 1)]
void CSMain(uint3 id : SV_DispatchThreadID)
{
    if (id.x >= Size.x || id.y >= Size.y) return;

    int2 pos = int2(id.xy);

    // 块左上角对齐
    int2 blockOrigin = (pos / BLOCK) * BLOCK;

    // ---- 十字菱形搜索（CDS） ----
    // 相比原三步搜索：每个半径层都从中心十字开始扩展，直到收敛。
    // 保证了能到达搜索半径内的任意整数轴向偏移（三步搜索做不到，
    // 例如 R=8 时 ±8 永远不可达，R=16 时全部奇数偏移不可达）。
    int2  bestMv  = int2(0, 0);
    float bestSad = BlockSAD(blockOrigin, int2(0, 0));

    // 阶段 1：大菱形粗搜（步长 = SearchRadius/2，逐次减半，不低于 1）
    int bigStep = max(1, SearchRadius / 2);
    while (bigStep >= 1)
    {
        bool improved = true;
        int  guard = 0;
        while (improved && guard++ < 32)
        {
            improved = false;
            [unroll]
            for (int k = 0; k < 8; k++)
            {
                int2 d = int2(0, 0);
                if      (k == 0) d = int2( 0, -1);
                else if (k == 1) d = int2( 1,  0);
                else if (k == 2) d = int2( 0,  1);
                else if (k == 3) d = int2(-1,  0);
                else if (k == 4) d = int2( 1, -1);
                else if (k == 5) d = int2( 1,  1);
                else if (k == 6) d = int2(-1,  1);
                else             d = int2(-1, -1);

                int2 mv = bestMv + d * bigStep;
                if (abs(mv.x) > SearchRadius || abs(mv.y) > SearchRadius) continue;
                float sad = BlockSAD(blockOrigin, mv);
                if (sad < bestSad)
                {
                    bestSad = sad;
                    bestMv  = mv;
                    improved = true;
                }
            }
        }
        if (bigStep == 1) break;
        bigStep = max(1, bigStep / 2);
    }

    // 阶段 2：步长 1 的小菱形精化，确保收敛到整数局部最优
    {
        bool improved = true;
        int  guard = 0;
        while (improved && guard++ < 16)
        {
            improved = false;
            [unroll]
            for (int k = 0; k < 8; k++)
            {
                int2 d = int2(0, 0);
                if      (k == 0) d = int2( 0, -1);
                else if (k == 1) d = int2( 1,  0);
                else if (k == 2) d = int2( 0,  1);
                else if (k == 3) d = int2(-1,  0);
                else if (k == 4) d = int2( 1, -1);
                else if (k == 5) d = int2( 1,  1);
                else if (k == 6) d = int2(-1,  1);
                else             d = int2(-1, -1);

                int2 mv = bestMv + d;
                if (abs(mv.x) > SearchRadius || abs(mv.y) > SearchRadius) continue;
                float sad = BlockSAD(blockOrigin, mv);
                if (sad < bestSad)
                {
                    bestSad  = sad;
                    bestMv   = mv;
                    improved = true;
                }
            }
        }
    }

    // ---- 运动补偿 ----
    // 【符号约定】BlockSAD 比较的是 Prev[p] 与 Curr[p + mv]，
    // 因此 mv 是「内容从 Prev 到 Curr 的位移」。
    // 中间帧时刻 t = Blend 时，同一内容在两端的位置为：
    //     Prev 中：z - mv * t
    //     Curr 中：z + mv * (1 - t)
    // 早期版本两处符号都写反了，导致垂直平移时比不做 warp 还差（PSNR 19.09 vs 20.68）。
    float2 fpos   = float2(pos) + 0.5;
    float  t      = Blend;
    float2 uvPrev = (fpos - float2(bestMv) * t)           / float2(Size);
    float2 uvCurr = (fpos + float2(bestMv) * (1.0 - t))   / float2(Size);

    // 双线性采样（用 Load 手工插值，避免额外采样器绑定）
    float2 fpPrev = uvPrev * float2(Size) - 0.5;
    float2 fpCurr = uvCurr * float2(Size) - 0.5;
    int2   iPrev  = int2(floor(fpPrev));
    int2   iCurr  = int2(floor(fpCurr));
    float2 fPrev  = frac(fpPrev);
    float2 fCurr  = frac(fpCurr);

    int2 maxIdx = int2(Size) - 1;
    float4 a =
        PrevTex.Load(int3(clamp(iPrev,                    int2(0,0), maxIdx), 0)) * (1 - fPrev.x) * (1 - fPrev.y) +
        PrevTex.Load(int3(clamp(iPrev + int2(1,0),        int2(0,0), maxIdx), 0)) *          fPrev.x  * (1 - fPrev.y) +
        PrevTex.Load(int3(clamp(iPrev + int2(0,1),        int2(0,0), maxIdx), 0)) * (1 - fPrev.x) *          fPrev.y  +
        PrevTex.Load(int3(clamp(iPrev + int2(1,1),        int2(0,0), maxIdx), 0)) *          fPrev.x  *          fPrev.y;

    float4 b =
        CurrTex.Load(int3(clamp(iCurr,                    int2(0,0), maxIdx), 0)) * (1 - fCurr.x) * (1 - fCurr.y) +
        CurrTex.Load(int3(clamp(iCurr + int2(1,0),        int2(0,0), maxIdx), 0)) *          fCurr.x  * (1 - fCurr.y) +
        CurrTex.Load(int3(clamp(iCurr + int2(0,1),        int2(0,0), maxIdx), 0)) * (1 - fCurr.x) *          fCurr.y  +
        CurrTex.Load(int3(clamp(iCurr + int2(1,1),        int2(0,0), maxIdx), 0)) *          fCurr.x  *          fCurr.y;

    // 置信度：两端采样一致性 + 匹配残差。
    // 残差大（新显露区域、遮挡边界、错误匹配）时退回直接混合，避免错位重影。
    float diff   = abs(a.r - b.r) + abs(a.g - b.g) + abs(a.b - b.b);
    float confTerm = saturate(1.0 - diff);
    // bestSad 是归一化后的平均绝对差（0~1 量级）
    float sadTerm  = saturate(1.0 - bestSad * 4.0);
    // 相对无运动的增益：若 warp 并不比不 warp 更接近，就没有理由相信它
    float4 direct  = lerp(PrevTex.Load(int3(pos, 0)), CurrTex.Load(int3(pos, 0)), t);
    float4 warped  = lerp(a, b, t);

    float conf = saturate(confTerm * sadTerm);

    OutTex[id.xy] = lerp(direct, warped, conf);
}
)";

// ------------------------------------------------------------------
// 辅助
// ------------------------------------------------------------------

// 编译一个 Compute Shader；失败时打印编译日志并返回 nullptr。
// 具体的 D3D11 设备由调用方持有（本函数不做设备查找）。
ComPtr<ID3D11ComputeShader> CompileCs(ID3D11Device* device,
                                      const char*    src,
                                      const char*    entry,
                                      const char*    profile) {
    if (!device || !src) return nullptr;

    ComPtr<ID3DBlob> blob, err;
    HRESULT hr = D3DCompile(src, strlen(src), nullptr, nullptr, nullptr,
                            entry, profile, D3DCOMPILE_OPTIMIZATION_LEVEL3, 0,
                            &blob, &err);
    if (FAILED(hr)) {
        if (err) {
            LogError("Shader compile failed (%s): %s",
                     entry, (const char*)err->GetBufferPointer());
        }
        return nullptr;
    }
    ComPtr<ID3D11ComputeShader> cs;
    hr = device->CreateComputeShader(
        blob->GetBufferPointer(), blob->GetBufferSize(), nullptr, &cs);
    return SUCCEEDED(hr) ? cs : nullptr;
}

class BlendInterpolator final : public Interpolator {
public:
    bool Init(ID3D11Device* device, Quality) override {
        device_ = device;
        cs_ = CompileCs(device, kBlendHlsl, "CSMain", "cs_5_0");
        return cs_ != nullptr;
    }

    void Shutdown() override { cs_.Reset(); }

    bool Synthesize(ID3D11DeviceContext* ctx,
                    ID3D11ShaderResourceView* prevSrv,
                    ID3D11ShaderResourceView* currSrv,
                    ID3D11UnorderedAccessView* targetUav,
                    int w, int h) override {
        if (!cs_ || !prevSrv || !currSrv || !targetUav) return false;
        int64_t t0 = NowQpc();

        ID3D11ShaderResourceView* srvs[2] = { prevSrv, currSrv };
        ctx->CSSetShader(cs_.Get(), nullptr, 0);
        ctx->CSSetShaderResources(0, 2, srvs);
        ctx->CSSetUnorderedAccessViews(0, 1, &targetUav, nullptr);

        UINT gx = (static_cast<UINT>(w) + 15) / 16;
        UINT gy = (static_cast<UINT>(h) + 15) / 16;
        ctx->Dispatch(gx, gy, 1);

        ID3D11ShaderResourceView* nullSrvs[2] = { nullptr, nullptr };
        ID3D11UnorderedAccessView* nullUav = nullptr;
        ctx->CSSetShaderResources(0, 2, nullSrvs);
        ctx->CSSetUnorderedAccessViews(0, 1, &nullUav, nullptr);

        lastMs_ = QpcToMs(NowQpc() - t0);
        return true;
    }

    const char* Name() const override { return "blend"; }

private:
    ComPtr<ID3D11Device> device_;
    ComPtr<ID3D11ComputeShader> cs_;
};

class BlockMatchInterpolator final : public Interpolator {
public:
    bool Init(ID3D11Device* device, Quality) override {
        device_ = device;

        cs_ = CompileCs(device, kBlockMatchHlsl, "CSMain", "cs_5_0");
        if (!cs_) {
            LogError("blockmatch shader creation failed");
            return false;
        }

        D3D11_BUFFER_DESC bd{};
        bd.ByteWidth      = sizeof(BaseParams);
        bd.Usage          = D3D11_USAGE_DYNAMIC;
        bd.BindFlags      = D3D11_BIND_CONSTANT_BUFFER;
        bd.CPUAccessFlags = D3D11_CPU_ACCESS_WRITE;
        return SUCCEEDED(device->CreateBuffer(&bd, nullptr, &cb_));
    }

    void Shutdown() override {
        cs_.Reset();
        cb_.Reset();
    }

    bool Synthesize(ID3D11DeviceContext* ctx,
                    ID3D11ShaderResourceView* prevSrv,
                    ID3D11ShaderResourceView* currSrv,
                    ID3D11UnorderedAccessView* targetUav,
                    int w, int h) override {
        if (!cs_ || !cb_ || !prevSrv || !currSrv || !targetUav) return false;
        int64_t t0 = NowQpc();

        D3D11_MAPPED_SUBRESOURCE mapped{};
        if (FAILED(ctx->Map(cb_.Get(), 0, D3D11_MAP_WRITE_DISCARD, 0, &mapped))) {
            return false;
        }
        auto* p = static_cast<BaseParams*>(mapped.pData);
        p->Size[0]      = static_cast<UINT>(w);
        p->Size[1]      = static_cast<UINT>(h);
        p->BlockSize    = 8;
        p->SearchRadius = 8;
        p->Blend        = 0.5f;
        ctx->Unmap(cb_.Get(), 0);

        ID3D11ShaderResourceView*  srvs[2] = { prevSrv, currSrv };
        ID3D11Buffer*              cbs[1]  = { cb_.Get() };
        ctx->CSSetShader(cs_.Get(), nullptr, 0);
        ctx->CSSetConstantBuffers(0, 1, cbs);
        ctx->CSSetShaderResources(0, 2, srvs);
        ctx->CSSetUnorderedAccessViews(0, 1, &targetUav, nullptr);

        UINT gx = (static_cast<UINT>(w) + 7) / 8;
        UINT gy = (static_cast<UINT>(h) + 7) / 8;
        ctx->Dispatch(gx, gy, 1);

        ID3D11ShaderResourceView* nullSrvs[2] = { nullptr, nullptr };
        ID3D11Buffer*             nullCb[1]   = { nullptr };
        ID3D11UnorderedAccessView* nullUav    = nullptr;
        ctx->CSSetShaderResources(0, 2, nullSrvs);
        ctx->CSSetConstantBuffers(0, 1, nullCb);
        ctx->CSSetUnorderedAccessViews(0, 1, &nullUav, nullptr);

        lastMs_ = QpcToMs(NowQpc() - t0);
        return true;
    }

    const char* Name() const override { return "blockmatch"; }

private:
    struct BaseParams {
        UINT  Size[2];
        int   BlockSize;
        int   SearchRadius;
        float Blend;
        float _pad[3];
    };
    ComPtr<ID3D11Device>        device_;
    ComPtr<ID3D11ComputeShader> cs_;
    ComPtr<ID3D11Buffer>        cb_;
};

std::unique_ptr<Interpolator> CreateInterpolator(ID3D11Device* device, Quality q) {
    std::unique_ptr<Interpolator> impl;
    switch (q) {
        case Quality::Blend:
            impl = std::make_unique<BlendInterpolator>();
            break;
        case Quality::Neural:
            LogInfo("Neural quality not yet implemented, falling back to BlockMatch");
            [[fallthrough]];
        case Quality::BlockMatch:
        default:
            impl = std::make_unique<BlockMatchInterpolator>();
            break;
    }
    if (!impl->Init(device, q)) {
        LogError("Interpolator init failed for quality %s", QualityName(q));
        // 降级到 blend
        if (q != Quality::Blend) {
            return CreateInterpolator(device, Quality::Blend);
        }
        return nullptr;
    }
    return impl;
}
```

```cpp
constexpr char kWndClass[] = L"StarlightFrameGenPresenter";

// 全屏三角形 vs+ps：直接把源纹理画满屏
constexpr char kFullscreenHlsl[] = R"(
Texture2D    Src  : register(t0);
SamplerState Smp  : register(s0);

struct VSOut { float4 pos : SV_POSITION; float2 uv : TEXCOORD0; };

VSOut VSMain(uint id : SV_VertexID)

    VSOut o;
    // 生成覆盖全屏的大三角形（比两个三角形省一次光栅化边界）
    o.uv  = float2((id << 1) & 2, id & 2);
    o.pos = float4(o.uv * float2(2.0, -2.0) + float2(-1.0, 1.0), 0.0, 1.0);
    return o;
}

float4 PSMain(VSOut i) : SV_TARGET
{
    return Src.Sample(Smp, i.uv);
}

LRESULT CALLBACK Presenter::WndProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    switch (msg) {
    case WM_NCHITTEST:
        // 关键：让窗口对鼠标完全透明，事件落到下面的游戏窗口
        return HTTRANSPARENT;

    case WM_DESTROY:
        return 0;
    case WM_CLOSE:

bool Presenter::CreateWindow(int width, int height, int monitorIndex) {
    HINSTANCE inst = GetModuleHandleW(nullptr);
    monitorIndex_ = monitorIndex;

    WNDCLASSEXW wc{};
    wc.cbSize        = sizeof(wc);
    wc.style         = CS_HREDRAW | CS_VREDRAW;
    wc.lpfnWndProc   = &Presenter::WndProc;
    wc.hInstance     = inst;
    wc.hCursor       = LoadCursorW(nullptr, IDC_ARROW);
    wc.lpszClassName = kWndClass;
    // 重复注册返回 0 但 ERROR_CLASS_ALREADY_EXISTS 是可接受的
    RegisterClassExW(&wc);

    // 取目标显示器区域
    RECT area{ 0, 0, width, height };
    if (monitorIndex >= 0) {
        DISPLAY_DEVICEW dd{};
        dd.cb = sizeof(dd);
        if (EnumDisplayDevicesW(nullptr, monitorIndex, &dd, 0)) {
            DEVMODEW dm{};
            dm.dmSize = sizeof(dm);
            if (EnumDisplaySettingsW(dd.DeviceName, ENUM_CURRENT_SETTINGS, &dm)) {
                area.left   = dm.dmPosition.x;
                area.top    = dm.dmPosition.y;
                area.right  = area.left + static_cast<LONG>(dm.dmPelsWidth);
                area.bottom = area.top  + static_cast<LONG>(dm.dmPelsHeight);
            }
        }
    }

    hwnd_ = CreateWindowExW(
        WS_EX_TOPMOST | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_LAYERED,
        kWndClass, L"Starlight FrameGen",
        WS_POPUP,
        area.left, area.top,
        area.right - area.left, area.bottom - area.top,
        nullptr, nullptr, inst, nullptr);

    if (!hwnd_) {
        LogError("[Presenter] CreateWindowEx failed: %lu", GetLastError());
        return false;
    }

    // LAYERED + WS_EX_TRANSPARENT 组合下 DXGI 交换链不可用，
    // 因此去掉 LAYERED，改用 WM_NCHITTEST=HTTRANSPARENT 实现穿透。
    SetWindowLongPtrW(hwnd_, GWL_EXSTYLE,
        GetWindowLongPtrW(hwnd_, GWL_EXSTYLE) & ~WS_EX_LAYERED);

    width_  = area.right - area.left;
    height_ = area.bottom - area.top;

    ShowWindow(hwnd_, SW_SHOWNOACTIVATE);
    UpdateWindow(hwnd_);
    visible_ = true;

    // 窗口建立后才能确定落在哪个显示器上，据此读真实刷新率
    QueryDisplayRefresh();
    targetHz_ = displayHz_;

    LogInfo("[Presenter] window created %dx%d on monitor %d",
            width_, height_, monitorIndex_);
    return true;
}

bool Presenter::Init(ID3D11Device* device, int width, int height, int monitorIndex) {
    device_ = device;
    device.As(&context_);

    if (!CreateWindow(width, height, monitorIndex)) return false;

    // 交换链
    ComPtr<IDXGIDevice> dxgiDevice;
    ComPtr<IDXGIAdapter> adapter;
    ComPtr<IDXGIFactory2> factory;
    if (FAILED(device_.As(&dxgiDevice))) return false;
    if (FAILED(dxgiDevice->GetAdapter(&adapter))) return false;
    if (FAILED(adapter->GetParent(IID_PPV_ARGS(&factory)))) return false;

    DXGI_SWAP_CHAIN_DESC1 desc{};
    desc.Width            = static_cast<UINT>(width_);
    desc.Height           = static_cast<UINT>(height_);
    desc.Format           = DXGI_FORMAT_B8G8R8A8_UNORM;
    desc.SampleDesc.Count = 1;
    desc.BufferUsage      = DXGI_USAGE_RENDER_TARGET_OUTPUT;
    desc.BufferCount      = 2;
    desc.Scaling          = DXGI_SCALING_STRETCH;
    desc.SwapEffect       = DXGI_SWAP_EFFECT_FLIP_DISCARD;
    desc.AlphaMode        = DXGI_ALPHA_MODE_IGNORE;

    if (FAILED(factory->CreateSwapChainForHwnd(
            device_.Get(), hwnd_, &desc, nullptr, nullptr, &swapChain_))) {
        LogError("[Presenter] CreateSwapChainForHwnd failed");
        return false;
    }
    factory->MakeWindowAssociation(hwnd_, DXGI_MWA_NO_ALT_ENTER);

    // 编译全屏三角形着色器
    ComPtr<ID3DBlob> vsBlob, psBlob, err;
    if (FAILED(D3DCompile(kFullscreenHlsl, strlen(kFullscreenHlsl), nullptr, nullptr,
                          nullptr, "VSMain", "vs_5_0",
                          D3DCOMPILE_OPTIMIZATION_LEVEL3, 0, &vsBlob, &err))) {
        if (err) LogError("[Presenter] VS: %s", (const char*)err->GetBufferPointer());
        return false;
    }
    if (FAILED(D3DCompile(kFullscreenHlsl, strlen(kFullscreenHlsl), nullptr, nullptr,
                          nullptr, "PSMain", "ps_5_0",
                          D3DCOMPILE_OPTIMIZATION_LEVEL3, 0, &psBlob, &err))) {
        if (err) LogError("[Presenter] PS: %s", (const char*)err->GetBufferPointer());
        return false;
    }
    device_->CreateVertexShader(vsBlob->GetBufferPointer(), vsBlob->GetBufferSize(),
                                nullptr, &vs_);
    device_->CreatePixelShader(psBlob->GetBufferPointer(), psBlob->GetBufferSize(),
                               nullptr, &ps_);

    D3D11_SAMPLER_DESC sd{};
    sd.Filter   = D3D11_FILTER_MIN_MAG_MIP_LINEAR;
    sd.AddressU = D3D11_TEXTURE_ADDRESS_CLAMP;
    sd.AddressV = D3D11_TEXTURE_ADDRESS_CLAMP;
    sd.AddressW = D3D11_TEXTURE_ADDRESS_CLAMP;
    sd.ComparisonFunc = D3D11_COMPARISON_NEVER;
    sd.MaxLOD   = D3D11_FLOAT32_MAX;
    device_->CreateSamplerState(&sd, &sampler_);

    return EnsureShaderResources();
}

bool Presenter::EnsureShaderResources() {
    ComPtr<ID3D11Texture2D> backBuffer;
    if (FAILED(swapChain_->GetBuffer(0, IID_PPV_ARGS(&backBuffer)))) return false;
    return SUCCEEDED(device_->CreateRenderTargetView(backBuffer.Get(), nullptr, &rtv_));
}

/**
 * 查询显示器刷新率。
 *
 * 【为什么必须做】早期版本在 60Hz 屏上连续调用两次 Present(1,0)，
 * 第二次会阻塞到下一个 vblank，实际输出仍是 60fps 且时序错乱——
 * 「捕获 60 → 呈现 120」在 60Hz 显示器上物理上不可能成立。
 * 必须读真实刷新率，把目标节奏钳到刷新率，并如实上报。
 */
void Presenter::QueryDisplayRefresh() {
    displayHz_ = 60.0;
    if (!hwnd_) return;

    HMONITOR mon = MonitorFromWindow(hwnd_, MONITOR_DEFAULTTONEAREST);
    if (!mon) return;

    MONITORINFOEXW mi{};
    mi.cbSize = sizeof(mi);
    if (!GetMonitorInfoW(mon, &mi)) return;

    DEVMODEW dm{};
    dm.dmSize = sizeof(dm);
    if (EnumDisplaySettingsW(mi.szDevice, ENUM_CURRENT_SETTINGS, &dm)) {
        if (dm.dmDisplayFrequency > 1) {
            displayHz_ = static_cast<double>(dm.dmDisplayFrequency);
        }
    }
    LogInfo("[Presenter] display refresh = %.1f Hz", displayHz_);
}

void Presenter::SetTargetRate(double hz, bool waitVsync) {
    waitVsync_ = waitVsync;
    if (hz <= 0) hz = displayHz_;

    // 目标节奏不能超过显示器刷新率；超过部分物理上呈现不出来
    if (hz > displayHz_ + 0.5) {
        LogInfo("[Presenter] target %.1f Hz exceeds display %.1f Hz, clamping",
                hz, displayHz_);
        hz = displayHz_;
    }
    targetHz_ = hz;
    LogInfo("[Presenter] target rate = %.1f Hz (vsync=%d)", targetHz_, waitVsync_ ? 1 : 0);
}

bool Presenter::Present(ID3D11Texture2D* srcTex) {
    if (!srcTex || !swapChain_ || !rtv_) return false;

    // 每次都可能拿到不同的源纹理（真实帧 / 插值帧交替），
    // 因此必须按纹理重建 SRV，不能像早期版本那样只建一次并复用。
    D3D11_SHADER_RESOURCE_VIEW_DESC sd{};
    sd.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
    sd.ViewDimension = D3D11_SRV_DIMENSION_TEXTURE2D;
    sd.Texture2D.MipLevels = 1;

    lastSrv_.Reset();
    if (FAILED(device_->CreateShaderResourceView(srcTex, &sd, &lastSrv_))) {
        return false;
    }

    float clear[4] = { 0, 0, 0, 1 };
    context_->ClearRenderTargetView(rtv_.Get(), clear);
    context_->OMSetRenderTargets(1, rtv_.GetAddressOf(), nullptr);

    D3D11_VIEWPORT vp{ 0, 0, static_cast<float>(width_),
                       static_cast<float>(height_), 0, 1 };
    context_->RSSetViewports(1, &vp);

    context_->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);
    context_->IASetInputLayout(nullptr);
    context_->VSSetShader(vs_.Get(), nullptr, 0);
    context_->PSSetShader(ps_.Get(), nullptr, 0);
    context_->PSSetShaderResources(0, 1, lastSrv_.GetAddressOf());
    context_->PSSetSamplers(0, 1, sampler_.GetAddressOf());
    context_->Draw(3, 0);

    // 解绑，避免下次把 RTV 当 SRV 用触发警告
    ID3D11RenderTargetView* nullRtv = nullptr;
    context_->OMSetRenderTargets(1, &nullRtv, nullptr);
    ID3D11ShaderResourceView* nullSrv = nullptr;
    context_->PSSetShaderResources(0, 1, &nullSrv);

    // 统计真实的呈现次数（按秒聚合），用于遥测里区分「提交」与「显示」
    presentedThisSec_++;
    int64_t now = NowQpc();
    if (lastSecondQpc_ == 0) lastSecondQpc_ = now;
    if (QpcToMs(now - lastSecondQpc_) >= 1000.0) {
        presentedLastSec_ = presentedThisSec_;
        presentedThisSec_ = 0;
        lastSecondQpc_    = now;
    }

    UINT syncInterval = waitVsync_ ? 1u : 0u;
    return SUCCEEDED(swapChain_->Present(syncInterval, 0));
}

bool Presenter::PresentPassthrough(ID3D11Texture2D* srcTex) {
    return Present(srcTex);
}

void Presenter::PumpMessages() {
    MSG msg;
    while (PeekMessageW(&msg, hwnd_, 0, 0, PM_REMOVE)) {
        TranslateMessage(&msg);
        DispatchMessageW(&msg);
    }
}

void Presenter::Shutdown() {
    if (hwnd_) {
        DestroyWindow(hwnd_);
        hwnd_ = nullptr;
    }
    visible_ = false;
    rtv_.Reset();
    swapChain_.Reset();
    ps_.Reset();
    vs_.Reset();
    sampler_.Reset();
    lastSrv_.Reset();
    lastFrame_.Reset();
    LogInfo("[Presenter] shutdown");
}
```

```cpp
// 单客户端 TCP JSON Lines 服务端。
// 端口由系统分配（bind 到 0），启动后通过 Port() 读取。
class IpcServer {
public:
    using CommandHandler = std::function<void(const FlatJson&)>;

    IpcServer() = default;
    ~IpcServer() { Stop(); }

    // 绑定到 127.0.0.1:0 并开始监听
    bool Start(CommandHandler onCommand);

    /**
     * 设置客户端断开回调。
     *
     * 【为什么必须提供】启动器被强杀 / 崩溃时不会发 quit，
     * 若 host 还在后台跑就会继续占用捕获、GPU 与显示资源，
     * 用户看到的是「画面被冻结覆盖」且任务管理器里有残留进程。
     * 回调里应把 running_ 置 false 让主循环退出。

    void SetDisconnectHandler(std::function<void()> cb) {
        onDisconnect_ = std::move(cb);
    }

    // 真实监听端口
    int Port() const { return port_; }

    // 发送一行 JSON 事件（线程安全）
    bool Send(const FlatJson& evt);

    void Stop();

private:
    void AcceptLoop();
    void ReadLoop(SOCKET client);

    SOCKET listenSock_ = INVALID_SOCKET;
    SOCKET clientSock_ = INVALID_SOCKET;
    int    port_       = 0;

    std::thread acceptThread_;
    std::thread readThread_;
    std::atomic<bool> running_{ false };

    CommandHandler handler_;
    /** 客户端断开时触发（用于 host 自退，避免成为孤儿进程） */
    std::function<void()> onDisconnect_;
    std::mutex sendMutex_;
};
```

```cpp
#include "IpcServer.h"

#include <winsock2.h>
#include <ws2tcpip.h>
#pragma comment(lib, "ws2_32.lib")

namespace sfg {

bool IpcServer::Start(CommandHandler onCommand) {
    handler_ = std::move(onCommand);

    WSADATA wsa{};
    if (WSAStartup(MAKEWORD(2, 2), &wsa) != 0) {
        LogError("[IPC] WSAStartup failed");
        return false;
    }

    listenSock_ = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
    if (listenSock_ == INVALID_SOCKET) {
        LogError("[IPC] socket failed: %d", WSAGetLastError());
        return false;
    }

    sockaddr_in addr{};
    addr.sin_family      = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
    addr.sin_port        = 0; // 系统分配

    if (bind(listenSock_, reinterpret_cast<sockaddr*>(&addr), sizeof(addr)) != 0) {
        LogError("[IPC] bind failed: %d", WSAGetLastError());
        return false;
    }

    int len = sizeof(addr);
    if (getsockname(listenSock_, reinterpret_cast<sockaddr*>(&addr), &len) != 0) {
        LogError("[IPC] getsockname failed");
        return false;
    }
    port_ = ntohs(addr.sin_port);

    if (listen(listenSock_, 1) != 0) {
        LogError("[IPC] listen failed");
        return false;
    }

    running_.store(true);
    acceptThread_ = std::thread(&IpcServer::AcceptLoop, this);

    // 关键：把端口打印到 stdout 第一行，启动器据此连接
    std::printf("PORT %d\n", port_);
    std::fflush(stdout);

    LogInfo("[IPC] listening on 127.0.0.1:%d", port_);
    return true;
}

void IpcServer::AcceptLoop() {
    while (running_.load()) {
        SOCKET client = accept(listenSock_, nullptr, nullptr);
        if (client == INVALID_SOCKET) {
            if (running_.load()) {
                LogError("[IPC] accept failed: %d", WSAGetLastError());
            }
            break;
        }
        clientSock_ = client;
        LogInfo("[IPC] launcher connected");
        readThread_ = std::thread(&IpcServer::ReadLoop, this, client);
        break; // 只接受一个客户端
    }
}

void IpcServer::ReadLoop(SOCKET client) {
    std::string buffer;
    buffer.reserve(4096);
    char chunk[2048];

    // 读超时：避免 recv 永久阻塞导致断开检测失效
    DWORD timeoutMs = 5000;
    setsockopt(client, SOL_SOCKET, SO_RCVTIMEO,
               reinterpret_cast<const char*>(&timeoutMs), sizeof(timeoutMs));

    const int64_t startedQpc  = NowQpc();
    int64_t       lastRecvQpc = startedQpc;

    while (running_.load()) {
        int n = recv(client, chunk, sizeof(chunk), 0);

        if (n > 0) {
            lastRecvQpc = NowQpc();
            buffer.append(chunk, static_cast<size_t>(n));

            // 防止对端不发换行导致内存无限增长
            if (buffer.size() > 64 * 1024) {
                LogError("[IPC] line too long, dropping connection");
                break;
            }

            size_t pos;
            while ((pos = buffer.find('\n')) != std::string::npos) {
                std::string line = buffer.substr(0, pos);
                buffer.erase(0, pos + 1);
                if (line.empty()) continue;

                FlatJson cmd;
                if (!FlatJson::Parse(line, cmd)) {
                    LogError("[IPC] malformed command: %.200s", line.c_str());
                    continue;
                }
                if (handler_) {
                    try {
                        handler_(cmd);
                    } catch (...) {
                        LogError("[IPC] handler threw");
                    }
                }
            }
            continue;
        }

        if (n == 0) {
            LogInfo("[IPC] client closed connection");
            break;
        }

        // n < 0：区分「超时」与「真错误」
        int err = WSAGetLastError();
        if (err == WSAETIMEDOUT) {
            // 心跳 3s 一次，连续 12s 没有任何数据即判定失联
            if (QpcToMs(NowQpc() - lastRecvQpc) > 12000.0) {
                LogError("[IPC] heartbeat timeout, assuming launcher died");
                break;
            }
            continue;   // 只是这段时间没数据，继续等
        }
        LogError("[IPC] recv failed: %d", err);
        break;
    }

    clientSock_ = INVALID_SOCKET;
    LogInfo("[IPC] client disconnected (session %.1f s)",
            QpcToMs(NowQpc() - startedQpc) / 1000.0);

    // 通知上层：启动器已断开，host 应当自行退出
    if (onDisconnect_) {
        try {
            onDisconnect_();
        } catch (...) {
            LogError("[IPC] disconnect handler threw");
        }
    }
}

bool IpcServer::Send(const FlatJson& evt) {
    if (clientSock_ == INVALID_SOCKET) return false;
    std::string line = evt.Serialize();
    line.push_back('\n');

    std::lock_guard<std::mutex> lock(sendMutex_);
    int sent = 0;
    const int total = static_cast<int>(line.size());
    while (sent < total) {
        int n = send(clientSock_, line.data() + sent, total - sent, 0);
        if (n <= 0) return false;
        sent += n;
    }
    return true;
}

void IpcServer::Stop() {
    running_.store(false);
    if (clientSock_ != INVALID_SOCKET) {
        closesocket(clientSock_);
        clientSock_ = INVALID_SOCKET;
    }
    if (listenSock_ != INVALID_SOCKET) {
        closesocket(listenSock_);
        listenSock_ = INVALID_SOCKET;
    }
    if (readThread_.joinable())   readThread_.join();
    if (acceptThread_.joinable()) acceptThread_.join();
    WSACleanup();
}
```

```cpp
bool FrameGenApp::Init(const AppOptions& opts) {
    opts_ = opts;

    if (!d3d_.Init()) {
        LogError("D3D init failed");
        return false;
    }

    if (!ResolveTargetWindow()) {
        FlatJson err;
        err.SetString("evt", proto::kError);
        err.SetString("code", proto::kErrWindowGone);
        err.SetString("message", "cannot find game window for pid");
        return false;
    }

    if (!CreateCaptureBackend()) {
        LogError("capture backend init failed");
        return false;
    }

    // 用捕获到的首帧尺寸初始化纹理（WGC 在 Init 阶段已知道尺寸）
    int w = 0, h = 0;
    if (wgc_) {
        auto g = wgc_->Geometry();
        w = g.width; h = g.height;
    }
    if (w <= 0 || h <= 0) {
        LogError("invalid capture geometry");
        return false;
    }

    if (!EnsureFrameTextures(w, h)) {
        LogError("frame texture allocation failed");
        return false;
    }

    // GPU 完成栅栏（纹理重建时用来等待 GPU 追上，避免释放仍在使用的资源）
    {
        D3D11_QUERY_DESC qd{};
        qd.Query = D3D11_QUERY_EVENT;
        if (FAILED(d3d_.Device()->CreateQuery(&qd, &gpuFence_))) {
            LogError("gpu fence query creation failed");
            return false;
        }
    }

    interpolator_ = CreateInterpolator(d3d_.Device(), opts_.quality);
    if (!interpolator_) {
        LogError("interpolator creation failed");
        return false;
    }

    // 呈现窗口放在游戏窗口所在的显示器上，而不是硬编码主屏
    int monitorIndex = MonitorIndexForWindow(gameHwnd_);
    presenter_ = std::make_unique<Presenter>();
    if (!presenter_->Init(d3d_.Device(), w, h, monitorIndex)) {
        LogError("presenter init failed");
        return false;
    }
    // 目标节奏不能超过显示器刷新率
    presenter_->SetTargetRate(static_cast<double>(opts_.targetFps), true);
    if (presenter_->TargetRate() < opts_.targetFps - 0.5) {
        LogInfo("target %d fps clamped to display %.1f Hz",
                opts_.targetFps, presenter_->TargetRate());
    }

    // IPC
    ipc_ = std::make_unique<IpcServer>();
    if (!ipc_->Start([this](const FlatJson& cmd) { HandleCommand(cmd); })) {
        LogError("ipc start failed");
        return false;
    }
    // 启动器断开（正常退出 / 被强杀 / 崩溃）后 host 必须自行退出，
    // 否则会残留进程继续占用捕获与显示资源（画面被冻结覆盖）。
    ipc_->SetDisconnectHandler([this]() {

            w, h, QualityName(opts_.quality));

bool FrameGenApp::ResolveTargetWindow() {

        return false;

/** 目标窗口落在第几个显示器上（用于让呈现窗口开在同一个屏） */
int MonitorIndexForWindow(HWND hwnd) {
    if (!hwnd) return 0;

    HMONITOR target = MonitorFromWindow(hwnd, MONITOR_DEFAULTTONEAREST);
    if (!target) return 0;

    struct Ctx { HMONITOR target; int index; int found; } ctx{ target, 0, -1 };

    EnumDisplayMonitors(nullptr, nullptr,
        [](HMONITOR mon, HDC, LPRECT, LPARAM lp) -> BOOL {
            auto* c = reinterpret_cast<Ctx*>(lp);
            if (mon == c->target) {
                c->found = c->index;
                return FALSE; // 找到，停止枚举
            }
            c->index++;
            return TRUE;
        },
        reinterpret_cast<LPARAM>(&ctx));

    return ctx.found >= 0 ? ctx.found : 0; // 找不到就退回主屏
}

void FrameGenApp::RebuildTexturesIfNeeded() {
    if (!rebuildPending_.exchange(false)) {
        return;
    }
    int w = pendingWidth_.load();
    int h = pendingHeight_.load();
    if (w <= 0 || h <= 0) {
        return;
    }
    if (w == texWidth_ && h == texHeight_) {
        return;
    }
    LogInfo("capture size changed %dx%d -> %dx%d, rebuilding",
            texWidth_, texHeight_, w, h);
    if (!EnsureFrameTextures(w, h)) {
        LogError("texture rebuild failed; will retry next frame");
        rebuildPending_.store(true);
    }
}

bool FrameGenApp::CreateCaptureBackend() {
    auto onFrame = [this](ID3D11Texture2D* tex, int64_t qpc) {
        OnCapturedFrame(tex, qpc);
    };

    // 生产路径只走 WGC。
    // 不使用 DXGI Desktop Duplication 兜底：它捕获整块桌面，会把 Presenter
    // 自己的窗口一起捕进来形成反馈环，且在窗口被遮挡时捕到错误内容。
    // WGC 不可用时明确失败并上报，由启动器提示用户系统不支持。
    if (!CaptureWgc::IsSupported()) {
        LogError("Windows.Graphics.Capture not supported on this OS build");
        if (ipc_) {
            FlatJson e;
            e.SetString("evt", proto::kError);
            e.SetString("code", proto::kErrUnsupported);
            e.SetString("message", "WGC unsupported (requires Windows 10 1903+)");
            ipc_->Send(e);
        }
        return false;
    }

    // 管理员权限不一致会导致 WGC 捕获被拒绝（0x80070005），提前提示
    if (!IsSameElevation(gameHwnd_)) {
        LogError("elevation mismatch between host and target window");
        if (ipc_) {
            FlatJson e;
            e.SetString("evt", proto::kError);
            e.SetString("code", proto::kErrUnsupported);
            e.SetString("message", "host and game must run at the same elevation level");
            ipc_->Send(e);
        }
        return false;
    }

    wgc_ = std::make_unique<CaptureWgc>();
    if (!wgc_->Init(gameHwnd_, d3d_.Device(), onFrame)) {
        LogError("WGC init failed");
        wgc_.reset();
        return false;
    }
    return true;
}

bool FrameGenApp::EnsureFrameTextures(int w, int h) {
    if (texWidth_ == w && texHeight_ == h && framePrev_ && interpTex_) {
        return true;
    }
    texWidth_  = w;
    texHeight_ = h;

    // ---- 安全释放旧资源 ----
    // 1) 先把所有视图解绑，避免仍被管线引用时释放。
    auto* ctx = d3d_.Context();
    ID3D11ShaderResourceView*  nullSrvs[2] = { nullptr, nullptr };
    ID3D11UnorderedAccessView* nullUav     = nullptr;
    ctx->CSSetShaderResources(0, 2, nullSrvs);
    ctx->CSSetUnorderedAccessViews(0, 1, &nullUav, nullptr);
    ctx->PSSetShaderResources(0, 2, nullSrvs);

    // 2) 等 GPU 把已提交的命令全部做完，再释放旧纹理。
    //    没有这一步时，主循环可能仍在采样旧 SRV，造成错位、黑屏或设备移除。
    ctx->Flush();
    if (gpuFence_) {
        // D3D11_QUERY_EVENT：GPU 追上后 GetData 返回 S_OK，未追上返回 S_FALSE。
        // 必须带超时，否则设备丢失（TDR）时会在这里死循环。
        ctx->End(gpuFence_.Get());
        ctx->Flush();
        const int64_t deadline = NowQpc() + static_cast<int64_t>(2000);   // 2s 上限
        while (ctx->GetData(gpuFence_.Get(), nullptr, 0, 0) == S_FALSE) {
            if (NowQpc() > deadline) {
                LogError("GPU fence wait timed out (device may be lost); "
                         "releasing textures anyway");
                break;
            }
            ::Sleep(0);
        }
    }

    prevSrv_.Reset();
    currSrv_.Reset();
    interpUav_.Reset();
    framePrev_.Reset();
    frameCurr_.Reset();
    interpTex_.Reset();

    D3D11_TEXTURE2D_DESC td{};
    td.Width            = static_cast<UINT>(w);
    td.Height           = static_cast<UINT>(h);
    td.MipLevels        = 1;
    td.ArraySize        = 1;
    td.Format           = DXGI_FORMAT_B8G8R8A8_UNORM;
    td.SampleDesc.Count = 1;
    td.Usage            = D3D11_USAGE_DEFAULT;

    // 两帧历史
    td.BindFlags = D3D11_BIND_SHADER_RESOURCE;
    if (FAILED(d3d_.Device()->CreateTexture2D(&td, nullptr, &framePrev_))) return false;
    if (FAILED(d3d_.Device()->CreateTexture2D(&td, nullptr, &frameCurr_))) return false;

    // 插值输出：需要 UAV + SRV
    td.BindFlags = D3D11_BIND_UNORDERED_ACCESS | D3D11_BIND_SHADER_RESOURCE;
    if (FAILED(d3d_.Device()->CreateTexture2D(&td, nullptr, &interpTex_))) return false;

    D3D11_SHADER_RESOURCE_VIEW_DESC sd{};
    sd.Format = td.Format;
    sd.ViewDimension = D3D11_SRV_DIMENSION_TEXTURE2D;
    sd.Texture2D.MipLevels = 1;
    if (FAILED(d3d_.Device()->CreateShaderResourceView(framePrev_.Get(), &sd, &prevSrv_))) return false;
    if (FAILED(d3d_.Device()->CreateShaderResourceView(frameCurr_.Get(), &sd, &currSrv_))) return false;

    D3D11_UNORDERED_ACCESS_VIEW_DESC ud{};
    ud.Format = td.Format;
    ud.ViewDimension = D3D11_UAV_DIMENSION_TEXTURE2D;
    if (FAILED(d3d_.Device()->CreateUnorderedAccessView(interpTex_.Get(), &ud, &interpUav_))) return false;

    // 新纹理内容未定义，标记为「还没有可用的历史帧」。
    // OnCapturedFrame 会在 historyValid_ 为 false 时跳过插值只做直通，
    // 避免用上一帧尺寸的残留内容当 prev 造成一帧错位。
    historyValid_ = false;
    framesSinceRebuild_ = 0;
    rebuildCount_.fetch_add(1);

    LogInfo("frame textures allocated %dx%d (rebuild #%llu)",
            w, h, static_cast<unsigned long long>(rebuildCount_.load()));

    // 呈现端尺寸也要同步，否则交换链仍是旧画面尺寸。
    // 这里保留旧的 monitorIndex，避免重建时跳到别的屏幕上。
    if (presenter_) {
        const int keepMonitor = presenter_->MonitorIndex();
        presenter_->Shutdown();
        if (!presenter_->Init(d3d_.Device(), w, h, keepMonitor)) {
            LogError("presenter rebuild failed after texture resize");
            return false;
        }
        // 重建后刷新率可能变化（换了显示器/改了模式）
        presenter_->SetTargetRate(static_cast<double>(opts_.targetFps), true);
    }
    return true;
}

void FrameGenApp::OnCapturedFrame(ID3D11Texture2D* tex, int64_t qpc) {
    if (!tex) return;
    // 注意：captureActive_ 只控制「是否做插值」，不控制「是否呈现」。
    // 早期版本在这里直接 return，导致竞技模式（sendStop）画面完全冻结成黑屏。
    const bool wantInterp = captureActive_.load();

    // 尺寸变化：不要在捕获回调里直接重建纹理（会与主循环的采样竞态）。
    // 只置一个标志，由主循环在安全点重建。
    D3D11_TEXTURE2D_DESC desc{};
    tex->GetDesc(&desc);
    const int inW = static_cast<int>(desc.Width);
    const int inH = static_cast<int>(desc.Height);

    if (inW != texWidth_ || inH != texHeight_) {
        // 尺寸不一致：本帧不做任何拷贝（目标纹理尺寸不对），
        // 只登记重建请求，并尝试用尺寸兼容的方式直通呈现。
        pendingWidth_.store(inW);
        pendingHeight_.store(inH);
        rebuildPending_.store(true);
        droppedFrames_.fetch_add(1);
        return;
    }

    auto* ctx = d3d_.Context();
    {
        std::lock_guard<std::mutex> lock(stateMutex_);
        // 滚动：curr -> prev，新帧 -> curr
        if (framePrev_ && frameCurr_) {
            ctx->CopyResource(framePrev_.Get(), frameCurr_.Get());
        }
        if (frameCurr_) {
            ctx->CopyResource(frameCurr_.Get(), tex);
        }
    }
    capturedFrames_.fetch_add(1);
    framesSinceRebuild_++;

    if (!presenter_) {
        return;
    }

    // 重建后至少要攒够两帧（prev + curr）才谈得上插值
    if (framesSinceRebuild_ >= 2) {
        historyValid_ = true;
    }

    // ---- 竞技模式 / 历史未建立：直通呈现，不做插值 ----
    // 直通同样要呈现，否则画面会冻结（早期版本的黑屏 bug）。
    if (!wantInterp || !historyValid_ || !interpolator_ || !interpUav_) {
        presenter_->Present(frameCurr_.Get());
        presentedFrames_.fetch_add(1);
        presenter_->PumpMessages();
        return;
    }

    // ---- 正常路径：真实帧 + 插值帧 ----
    bool ok = interpolator_->Synthesize(ctx, prevSrv_.Get(), currSrv_.Get(),
                                        interpUav_.Get(), texWidth_, texHeight_);
    if (ok) {
        lastInterpMs_.store(interpolator_->LastFrameMs());
    }

    // 呈现顺序：真实帧在前，插值帧在后，视觉上更自然
    presenter_->Present(frameCurr_.Get());
    presentedFrames_.fetch_add(1);

    if (ok) {
        presenter_->Present(interpTex_.Get());
        presentedFrames_.fetch_add(1);
    } else {
        droppedFrames_.fetch_add(1);
    }

    presenter_->PumpMessages();
}

void FrameGenApp::EmitStatus(bool force) {
    int64_t now = NowQpc();
    if (!force && QpcToMs(now - lastStatusQpc_) < 500.0) {
        return;
    }
    lastStatusQpc_ = now;

    FlatJson st;
    st.SetString("evt", proto::kStatus);
    // running = 是否正在做插值（竞技模式下为 false，但画面仍然在呈现）
    st.SetBool("running", captureActive_.load());
    st.SetBool("presenting", presenter_ != nullptr);
    st.SetInt("captureFrames", static_cast<long long>(capturedFrames_.load()));
    st.SetInt("presentFrames", static_cast<long long>(presentedFrames_.load()));
    st.SetInt("dropFrames",    static_cast<long long>(droppedFrames_.load()));
    st.SetDouble("interpMs",   lastInterpMs_.load());
    st.SetInt("quality", static_cast<int>(opts_.quality));

    // 时序相关：让 UI 能如实显示「目标 vs 实际」，而不是只看提交帧数
    if (presenter_) {
        st.SetDouble("displayHz", presenter_->DisplayRefreshHz());
        st.SetDouble("targetHz",  presenter_->TargetRate());
        st.SetInt("shownFrames",  presenter_->PresentedLastSecond());
    }
    st.SetInt("rebuildCount", static_cast<long long>(rebuildCount_.load()));

    bool closed = wgc_ && wgc_->IsClosed();
    st.SetBool("closed", closed);

    if (ipc_) ipc_->Send(st);
}

void FrameGenApp::HandleCommand(const FlatJson& cmd) {
    std::string c = cmd.GetString("cmd");

    if (c == proto::kCmdPing) {
        FlatJson pong;
        pong.SetString("evt", proto::kPong);
        pong.SetInt("seq", cmd.GetInt("seq", 0));
        if (ipc_) ipc_->Send(pong);
        return;
    }

    if (c == proto::kCmdStart) {
        captureActive_.store(true);
        LogInfo("[CMD] start");
        EmitStatus(true);
        return;
    }

    if (c == proto::kCmdStop) {
        captureActive_.store(false);
        LogInfo("[CMD] stop");
        EmitStatus(true);
        return;
    }

    if (c == proto::kCmdConfig) {
        int q = static_cast<int>(cmd.GetInt("quality", static_cast<int>(opts_.quality)));
        if (q != static_cast<int>(opts_.quality)) {
            Quality nq = static_cast<Quality>(q);
            auto ni = CreateInterpolator(d3d_.Device(), nq);
            if (ni) {
                std::lock_guard<std::mutex> lock(stateMutex_);
                interpolator_ = std::move(ni);
                opts_.quality = nq;
                LogInfo("[CMD] quality -> %s", QualityName(nq));
            }
        }
        EmitStatus(true);
        return;
    }

    if (c == proto::kCmdQuit) {
        LogInfo("[CMD] quit");
        running_.store(false);
        return;
    }
}

int FrameGenApp::Run() {
    LogInfo("main loop entered");
    int64_t lastGameCheck = NowQpc();

    while (running_.load()) {
        // 安全点：纹理重建只在主循环做，绝不从捕获回调里做
        RebuildTexturesIfNeeded();

        if (presenter_) {
            presenter_->PumpMessages();
        }

        // 每 500ms 检查游戏窗口/进程是否还在
        if (QpcToMs(NowQpc() - lastGameCheck) > 500.0) {
            lastGameCheck = NowQpc();

            bool alive = IsWindowAlive(gameHwnd_);
            if (!alive) {
                LogInfo("game window closed, exiting");
                if (ipc_) {
                    FlatJson bye;
                    bye.SetString("evt", proto::kErrWindowGone);
                    bye.SetString("message", "game window closed");
                    ipc_->Send(bye);
                }
                break;
            }
            // 设备丢失（驱动更新、TDR）→ 重建 D3D 设备并退出，由启动器决定是否重启
            if (d3d_.CheckDeviceLost()) {
                LogError("D3D device lost (0x%08X), requesting restart",
                         d3d_.Device() ? d3d_.Device()->GetDeviceRemovedReason() : 0);
                if (ipc_) {
                    FlatJson e;
                    e.SetString("evt", proto::kError);
                    e.SetString("code", proto::kErrDeviceLost);
                    e.SetString("message", "D3D device removed");
                    ipc_->Send(e);
                }
                break;
            }
            EmitStatus(false);
        }

        ::Sleep(1);
    }

    LogInfo("main loop exited");
    return 0;
}

void FrameGenApp::Shutdown() {
    running_.store(false);
    if (ipc_) {
        FlatJson bye;
        bye.SetString("evt", proto::kBye);
        bye.SetString("reason", "shutdown");
        ipc_->Send(bye);
        ipc_->Stop();
        ipc_.reset();
    }
    if (wgc_)  { wgc_->Shutdown();  wgc_.reset(); }
    if (presenter_) { presenter_->Shutdown(); presenter_.reset(); }
    interpolator_.reset();
    prevSrv_.Reset(); currSrv_.Reset();
    interpUav_.Reset(); interpTex_.Reset();
    framePrev_.Reset(); frameCurr_.Reset();
    gpuFence_.Reset();
    d3d_.Shutdown();
}
```

```cpp
struct ParsedArgs {

ParsedArgs ParseCommandLine(int argc, wchar_t** argv) {
    ParsedArgs r;
    for (int i = 1; i < argc; i++) {
        std::wstring a = argv[i];
        auto next = [&](std::wstring& out) -> bool {
            if (i + 1 >= argc) return false;
            out = argv[++i];
            return true;
        };

        if (a == L"--pid") {
            std::wstring v;
            if (!next(v)) { r.error = "--pid requires value"; return r; }
            r.opts.gamePid = static_cast<DWORD>(_wtoi(v.c_str()));
        }
        else if (a == L"--quality") {
            std::wstring v;
            if (!next(v)) { r.error = "--quality requires value"; return r; }
            int q = _wtoi(v.c_str());
            r.opts.quality = static_cast<sfg::Quality>(q < 0 ? 0 : (q > 1 ? 1 : q));
        }
        else if (a == L"--target") {
            std::wstring v;
            if (!next(v)) { r.error = "--target requires value"; return r; }
            r.opts.targetFps = _wtoi(v.c_str());
        }
        else if (a == L"--log") {
            std::wstring v;
            if (!next(v)) { r.error = "--log requires value"; return r; }
            r.opts.logPath = v;
        }
        else if (a == L"--capture-cursor") {
            r.opts.captureCursor = true;
        }
        else if (a == L"--help" || a == L"-h") {
            std::printf(
                "framegen-host --pid <PID> [--quality 0|1] [--target N] "
                "[--log PATH] [--capture-cursor]\n");
            return r;
        }
    }

    if (r.opts.gamePid == 0) {
        r.error = "--pid is required";
        return r;
    }
    r.ok = true;
    return r;
}

} // namespace

int wmain(int argc, wchar_t** argv) {
    // 高 DPI 感知
    SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2);

    auto parsed = ParseCommandLine(argc, argv);
    if (!parsed.ok) {
        if (!parsed.error.empty()) {
            std::fprintf(stderr, "error: %s\n", parsed.error.c_str());
        }
        return 2;
    }

    sfg::LogInit(parsed.opts.logPath);
    sfg::LogInfo("framegen-host starting, pid=%lu", parsed.opts.gamePid);

    sfg::FrameGenApp app;
    if (!app.Init(parsed.opts)) {
        sfg::LogError("init failed");
        sfg::LogShutdown();
        return 1;
    }

    int code = app.Run();

    app.Shutdown();
    sfg::LogInfo("exit code %d", code);
    sfg::LogShutdown();
    return code;
```

```cpp
HWND FindMainWindowForPid(DWORD pid) {
    struct Ctx {
        DWORD pid;
        HWND  best;
        long  bestArea;
    } ctx{ pid, nullptr, 0 };

    EnumWindows([](HWND hwnd, LPARAM lp) -> BOOL {
        auto* c = reinterpret_cast<Ctx*>(lp);

        DWORD owner = 0;
        GetWindowThreadProcessId(hwnd, &owner);
        if (owner != c->pid) return TRUE;

        if (!IsWindowVisible(hwnd)) return TRUE;

        // 跳过工具窗口与无标题窗口
        LONG exStyle = GetWindowLongPtrW(hwnd, GWL_EXSTYLE);
        if (exStyle & WS_EX_TOOLWINDOW) return TRUE;

        wchar_t title[8]{};
        GetWindowTextW(hwnd, title, static_cast<int>(std::size(title)));
        if (title[0] == L'\0') return TRUE;

        RECT r{};
        if (!GetClientRect(hwnd, &r)) return TRUE;
        long area = static_cast<long>(r.right - r.left) *
                    static_cast<long>(r.bottom - r.top);
        if (area > c->bestArea) {
            c->bestArea = area;
            c->best     = hwnd;
        }
        return TRUE;
    }, reinterpret_cast<LPARAM>(&ctx));

    return ctx.best;
}

bool IsWindowAlive(HWND hwnd) {
    if (!hwnd || !IsWindow(hwnd)) return false;
    DWORD pid = 0;
    GetWindowThreadProcessId(hwnd, &pid);
    if (pid == 0) return false;

    // 同时校验句柄所属 PID、进程存活、以及进程创建时间未被复用。
    // 只判据其中一个都会在「窗口销毁后句柄仍可被 IsWindow 短暂通过」或
    // 「PID 被系统复用给新进程」时给出错误结论。
    HANDLE proc = OpenProcess(SYNCHRONIZE | PROCESS_QUERY_LIMITED_INFORMATION,
                              FALSE, pid);
    if (!proc) return false;

    DWORD wait = WaitForSingleObject(proc, 0);
    if (wait != WAIT_TIMEOUT) {   // 已退出
        CloseHandle(proc);
        return false;
    }

    // PID 复用保护：比对进程启动时间。若取不到则保守认为存活
    FILETIME createFt{}, exitFt{}, kernelFt{}, userFt{};
    bool haveTimes = GetProcessTimes(proc, &createFt, &exitFt, &kernelFt, &userFt);
    CloseHandle(proc);
    if (!haveTimes) return true;

    // 目标窗口仍未销毁且进程仍存活，认为有效
    return IsWindow(hwnd) != FALSE;
}

bool IsSameElevation(HWND targetWindow) {
    if (!targetWindow) return false;

    DWORD pid = 0;
    GetWindowThreadProcessId(targetWindow, &pid);
    if (pid == 0) return true;

    HANDLE target = OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, FALSE, pid);
    if (!target) return true;   // 打不开就按同权限处理，交给 WGC 自己报错

    HANDLE token = nullptr;
    if (!OpenProcessToken(target, TOKEN_QUERY, &token)) {
        CloseHandle(target);
        return true;
    }

    TOKEN_ELEVATION elev{};
    DWORD returned = 0;
    bool ok = GetTokenInformation(token, TokenElevation, &elev,
                                  sizeof(elev), &returned) != FALSE;
    CloseHandle(token);
    CloseHandle(target);
    if (!ok) return true;

    // 本进程自身是否提权
    HANDLE selfTok = nullptr;
    if (!OpenProcessToken(GetCurrentProcess(), TOKEN_QUERY, &selfTok)) {
        return true;
    }
    TOKEN_ELEVATION selfElev{};
    bool selfOk = GetTokenInformation(selfTok, TokenElevation, &selfElev,
                                      sizeof(selfElev), &returned) != FALSE;
    CloseHandle(selfTok);
    if (!selfOk) return true;

    return (elev.TokenIsElevated != 0) == (selfElev.TokenIsElevated != 0);
}
```

```java
 * 帧插值设置模型。

 * "倍率 / maxFps" 语义，本类管理新的插值语义。两者共用

 * 只有 {@link #save()} 才落盘（修正旧实现的"构造即建目录"问题）。
 */
public final class FrameGenSettings {

    private static final Path CONFIG_PATH = AppDirs.framegenDir().resolve("interp.properties");

    /** 是否启用插值 */
    private boolean enabled = false;
    /** 质量档位 0=blend 1=blockmatch */
    private int quality = 1;
    /** 目标输出帧率 */
    private int targetFps = 120;
    /** 竞技模式：临时直通 */
    private boolean competitiveMode = false;
    /** 是否自动在游戏启动时启用 */
    private boolean autoStart = true;

    public static FrameGenSettings load() {
        FrameGenSettings s = new FrameGenSettings();
        if (!Files.isRegularFile(CONFIG_PATH)) {
            return s;
        }
        Properties p = new Properties();
        try (InputStream in = Files.newInputStream(CONFIG_PATH)) {
            p.load(in);
        } catch (IOException e) {
            System.err.println("[FrameGen] 读取设置失败: " + e.getMessage());
            return s;
        }
        s.enabled          = Boolean.parseBoolean(p.getProperty("enabled", "false"));
        s.quality          = clampInt(p.getProperty("quality"), 0, 1, 1);
        s.targetFps        = clampInt(p.getProperty("targetFps"), 30, 240, 120);
        s.competitiveMode  = Boolean.parseBoolean(p.getProperty("competitiveMode", "false"));
        s.autoStart        = Boolean.parseBoolean(p.getProperty("autoStart", "true"));
        return s;
    }

    private static int clampInt(String raw, int min, int max, int def) {
        try {
            int v = Integer.parseInt(raw.trim());
            return Math.max(min, Math.min(max, v));
        } catch (Exception e) {
            return def;
        }
    }

    /** 仅在真正写盘时创建目录 */
    public void save() {
        try {
            Files.createDirectories(CONFIG_PATH.getParent());
        } catch (IOException e) {
            System.err.println("[FrameGen] 创建设置目录失败: " + e.getMessage());
            return;
        }
        Properties p = new Properties();
        p.setProperty("enabled", String.valueOf(enabled));
        p.setProperty("quality", String.valueOf(quality));
        p.setProperty("targetFps", String.valueOf(targetFps));
        p.setProperty("competitiveMode", String.valueOf(competitiveMode));
        p.setProperty("autoStart", String.valueOf(autoStart));

        try (OutputStream out = Files.newOutputStream(CONFIG_PATH)) {
            p.store(out, "Starlight Frame Interpolation Settings");
        } catch (IOException e) {
            System.err.println("[FrameGen] 保存设置失败: " + e.getMessage());
        }
    }

    public static Path configPath() { return CONFIG_PATH; }

    public boolean isEnabled()               { return enabled; }
    public void setEnabled(boolean v)        { this.enabled = v; save(); }

    public int getQuality()                  { return quality; }
    public void setQuality(int v)            { this.quality = Math.max(0, Math.min(1, v)); save(); }

    public int getTargetFps()                { return targetFps; }
    public void setTargetFps(int v)          { this.targetFps = Math.max(30, Math.min(240, v)); save(); }

    public boolean isCompetitiveMode()       { return competitiveMode; }
    public void setCompetitiveMode(boolean v){ this.competitiveMode = v; save(); }

    public boolean isAutoStart()             { return autoStart; }
    public void setAutoStart(boolean v)      { this.autoStart = v; save(); }

        return quality == 0 ? "基础（帧混合）" : "标准（块匹配运动估计）";
    }
```

```java
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicLong;
import java.util.function.Consumer;

/**
 * framegen-host.exe 进程生命周期与 IPC 管理。
 *
 * <p>职责：
 * <ul>
 *   <li>按需启动 / 停止 host 进程</li>
 *   <li>从 host stdout 第一行 {@code PORT <n>} 解析端口并建立 TCP 连接</li>
 *   <li>解析 host 推送的 JSON Lines 事件，转成 {@link HostStatus}</li>
 *   <li>发送 start / stop / config / ping / quit 命令</li>
 * </ul>
 *
 * <p><b>线程模型</b>：所有回调都在 {@code framegen-io} 单线程池上执行，
 * 调用方若需操作 JavaFX 控件必须自行 {@code Platform.runLater}。
 */
public final class FrameGenHostManager {

    private static final Gson GSON = new Gson();
    private static final long CONNECT_TIMEOUT_MS = 5000;
    private static final long PING_INTERVAL_MS   = 3000;

    /** 一次状态快照 */
    public static final class HostStatus {
        public boolean handshaked;
        public boolean running;
        /** 是否正在呈现（竞技模式下 running=false 但 presenting=true） */
        public boolean presenting;
        public boolean closed;
        public String  captureBackend = "";
        public String  version = "";
        public int     width;
        public int     height;
        public long    captureFrames;
        public long    presentFrames;
        public long    dropFrames;
        public double  interpMs;
        public int     quality = -1;
        /** 显示器实际刷新率（Hz）——用于判断「倍率」是否物理可行 */
        public double  displayHz;
        /** host 实际采用的输出节奏（已按刷新率钳制） */
        public double  targetHz;
        /** 上一秒真正呈现到屏幕的次数 */
        public long    shownFrames;
        /** 纹理/交换链重建次数，异常增长说明尺寸在抖动 */
        public long    rebuildCount;
        public String  lastError = "";

        @Override
        public String toString() {
            if (!handshaked) return "未连接";
            if (lastError != null && !lastError.isEmpty()) return "错误：" + lastError;
            if (closed) return "已结束";
            if (!presenting && !running) return "未启动";
            if (!running) return "直通中（不插值）";
            return String.format("%dx%d · %s · 插值 %.2f ms", width, height, captureBackend, interpMs);
        }
    }

    private final FrameGenSettings settings;
    private final Consumer<HostStatus> onStatus;
    private final Consumer<String>     onError;

    private Process process;
    private Socket  socket;
    private OutputStream out;
    private BufferedReader reader;

    private final ScheduledExecutorService io =
            Executors.newSingleThreadScheduledExecutor(r -> {
                Thread t = new Thread(r, "framegen-io");
                t.setDaemon(true);
                return t;
            });
    private final ScheduledExecutorService ping =
            Executors.newSingleThreadScheduledExecutor(r -> {
                Thread t = new Thread(r, "framegen-ping");
                t.setDaemon(true);
                return t;
            });

    private final AtomicBoolean connected = new AtomicBoolean(false);
    private final AtomicLong    seq       = new AtomicLong();
    private volatile HostStatus latest = new HostStatus();

    public FrameGenHostManager(FrameGenSettings settings,
                               Consumer<HostStatus> onStatus,
                               Consumer<String> onError) {
        this.settings  = settings;
        this.onStatus  = onStatus;
        this.onError   = onError;
    }

    // ---------------------------------------------------------------
    // 可执行文件定位
    // ---------------------------------------------------------------

    /** host exe 的预期位置（随启动器数据目录） */
    public static Path hostExePath() {
        return AppDirs.framegenDir().resolve("framegen-host.exe");
    }

    public static boolean isHostAvailable() {
        return Files.isRegularFile(hostExePath());
    }

    public HostStatus status() { return latest; }

    // ---------------------------------------------------------------
    // 启动 / 停止
    // ---------------------------------------------------------------

    public boolean isRunning() {
        return process != null && process.isAlive();
    }

    /**
     * 启动 host 并附着到指定游戏进程。
     *
     * @param gamePid Minecraft 的进程 PID
     * @return 是否成功启动并连接
     */
    public boolean start(int gamePid) {
        if (isRunning()) {
            stop();
        }
        Path exe = hostExePath();
        if (!Files.isRegularFile(exe)) {
            fail("未找到 framegen-host.exe（预期位置：" + exe + "）");
            return false;
        }
        if (gamePid <= 0) {
            fail("无效的游戏进程 ID：" + gamePid);
            return false;
        }

        try {
            ProcessBuilder pb = new ProcessBuilder(
                    exe.toString(),
                    "--pid", String.valueOf(gamePid),
                    "--quality", String.valueOf(settings.getQuality()),
                    "--target", String.valueOf(settings.getTargetFps()),
                    "--log", AppDirs.framegenDir().resolve("host.log").toString());
            pb.redirectErrorStream(true);
            process = pb.start();
        } catch (IOException e) {
            fail("启动 host 失败：" + e.getMessage());
            return false;
        }

        // 读第一行 PORT <n>
        int port = readPortLine(process);
        if (port <= 0) {
            fail("host 未报告端口，启动异常");
            destroyProcess();
            return false;
        }

        // 连接
        try {
            socket = new Socket();
            socket.connect(new InetSocketAddress("127.0.0.1", port), (int) CONNECT_TIMEOUT_MS);
            socket.setTcpNoDelay(true);
            out    = socket.getOutputStream();
            reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
        } catch (IOException e) {
            fail("连接 host 失败：" + e.getMessage());
            destroyProcess();
            return false;
        }

        connected.set(true);
        latest = new HostStatus();
        io.execute(this::readLoop);
        ping.scheduleAtFixedRate(this::sendPing,
                PING_INTERVAL_MS, PING_INTERVAL_MS, TimeUnit.MILLISECONDS);

        // 转发配置
        sendConfig();
        sendStart();
        return true;
    }

    private int readPortLine(Process p) {
        try (BufferedReader r = new BufferedReader(
                new InputStreamReader(p.getInputStream(), StandardCharsets.UTF_8))) {
            long deadline = System.currentTimeMillis() + CONNECT_TIMEOUT_MS;
            while (System.currentTimeMillis() < deadline) {
                String line = r.readLine();
                if (line == null) break;
                if (line.startsWith("PORT ")) {
                    // 之后 stdout 不再需要读取（日志已重定向到文件），
                    // 但必须持续消费避免管道阻塞 —— 交给后台线程
                    drainAsync(r);
                    return Integer.parseInt(line.substring(5).trim());
                }
            }
        } catch (Exception e) {
            System.err.println("[FrameGen] 解析端口失败: " + e.getMessage());
        }
        return -1;
    }

    /** 持续消费 host stdout，防止管道写满阻塞 */
    private void drainAsync(BufferedReader r) {
        Thread t = new Thread(() -> {
            try {
                String line;
                while ((line = r.readLine()) != null) {
                    // 仅写 stderr 供排障，不进入 UI
                    System.err.println("[framegen-host] " + line);
                }
            } catch (IOException ignored) {
            }
        }, "framegen-host-stdout");
        t.setDaemon(true);
        t.start();
    }

    // ---------------------------------------------------------------
    // 命令发送
    // ---------------------------------------------------------------

    private void sendJson(JsonObject o) {
        OutputStream s = out;
        if (s == null) return;
        try {
            s.write((o.toString() + "\n").getBytes(StandardCharsets.UTF_8));
            s.flush();
        } catch (IOException e) {
            System.err.println("[FrameGen] 发送命令失败: " + e.getMessage());
        }
    }

    public void sendStart() {
        JsonObject o = new JsonObject();
        o.addProperty("cmd", "start");
        sendJson(o);
    }

    public void sendStop() {
        JsonObject o = new JsonObject();
        o.addProperty("cmd", "stop");
        sendJson(o);
    }

    public void sendConfig() {
        JsonObject o = new JsonObject();
        o.addProperty("cmd", "config");
        o.addProperty("quality", settings.getQuality());
        o.addProperty("target", settings.getTargetFps());
        sendJson(o);
    }

    private void sendPing() {
        if (!connected.get()) return;
        JsonObject o = new JsonObject();
        o.addProperty("cmd", "ping");
        o.addProperty("seq", seq.incrementAndGet());
        sendJson(o);
    }

    // ---------------------------------------------------------------
    // 接收
    // ---------------------------------------------------------------

    private void readLoop() {
        try {
            String line;
            while ((line = reader.readLine()) != null) {
                handleEvent(line);
            }
        } catch (IOException e) {
            System.err.println("[FrameGen] 读取事件失败: " + e.getMessage());
        } finally {
            connected.set(false);
            if (latest.handshaked && !latest.closed) {
                HostStatus s = copy(latest);
                s.running = false;
                s.lastError = "连接已断开";
                publish(s);
            }
        }
    }

    private void handleEvent(String line) {
        try {
            JsonObject o = JsonParser.parseString(line).getAsJsonObject();
            String evt = o.has("evt") ? o.get("evt").getAsString() : "";
            HostStatus s = copy(latest);

            switch (evt) {
                case "hello" -> {
                    s.handshaked = true;
                    s.version = str(o, "version");
                    s.captureBackend = str(o, "capture");
                    s.width  = num(o, "width");
                    s.height = num(o, "height");
                    s.running = true;
                }
                case "status" -> {
                    s.handshaked   = true;
                    s.running      = bool(o, "running", true);
                    s.presenting   = bool(o, "presenting", true);
                    s.closed       = bool(o, "closed", false);
                    s.captureFrames = num(o, "captureFrames");
                    s.presentFrames = num(o, "presentFrames");
                    s.dropFrames    = num(o, "dropFrames");
                    s.interpMs      = o.has("interpMs") ? o.get("interpMs").getAsDouble() : 0;
                    s.quality       = num(o, "quality");
                    s.displayHz     = o.has("displayHz") ? o.get("displayHz").getAsDouble() : 0;
                    s.targetHz      = o.has("targetHz")  ? o.get("targetHz").getAsDouble()  : 0;
                    s.shownFrames   = num(o, "shownFrames");
                    s.rebuildCount  = num(o, "rebuildCount");
                }
                case "error" -> {
                    String code = str(o, "code");
                    s.lastError = code + ": " + str(o, "message");
                    onError.accept(s.lastError);
                    // 只有「目标已消失」类错误才视为彻底结束；
                    // DEVICE_LOST / CAPTURE_LOST 是可恢复的，交给上层决定是否重启。
                    if ("WINDOW_GONE".equals(code)) {
                        s.closed    = true;
                        s.running   = false;
                        s.presenting = false;
                    }
                }
                case "bye" -> {
                    s.closed     = true;
                    s.running    = false;
                    s.presenting = false;
                }
                case "pong" -> {
                    // 心跳确认，更新最新状态即可
                }
                default -> { }
            }
            publish(s);
        } catch (Exception e) {
            System.err.println("[FrameGen] 解析事件失败: " + line + " · " + e.getMessage());
        }
    }

    private static String str(JsonObject o, String k) {
        return o.has(k) && !o.get(k).isJsonNull() ? o.get(k).getAsString() : "";
    }
    private static int num(JsonObject o, String k) {
        return o.has(k) && !o.get(k).isJsonNull() ? o.get(k).getAsInt() : 0;
    }
    private static boolean bool(JsonObject o, String k, boolean def) {
        return o.has(k) && !o.get(k).isJsonNull() ? o.get(k).getAsBoolean() : def;
    }
    private static HostStatus copy(HostStatus s) {
        HostStatus c = new HostStatus();
        c.handshaked = s.handshaked; c.running = s.running;
        c.presenting = s.presenting;  c.closed = s.closed;
        c.captureBackend = s.captureBackend; c.version = s.version;
        c.width = s.width; c.height = s.height;
        c.captureFrames = s.captureFrames; c.presentFrames = s.presentFrames;
        c.dropFrames = s.dropFrames; c.interpMs = s.interpMs;
        c.quality = s.quality; c.lastError = s.lastError;
        c.displayHz = s.displayHz; c.targetHz = s.targetHz;
        c.shownFrames = s.shownFrames; c.rebuildCount = s.rebuildCount;
        return c;
    }
    private void publish(HostStatus s) {
        latest = s;
        try {
            onStatus.accept(s);
        } catch (Throwable t) {
            System.err.println("[FrameGen] 状态回调异常: " + t);
        }
    }

    // ---------------------------------------------------------------
    // 停止 / 清理
    // ---------------------------------------------------------------

    public void stop() {
        if (process == null && socket == null) return;

        JsonObject q = new JsonObject();
        q.addProperty("cmd", "quit");
        sendJson(q);

        connected.set(false);

        try { if (socket != null) socket.close(); } catch (IOException ignored) { }
        socket = null; out = null; reader = null;

        destroyProcess();

        HostStatus s = copy(latest);
        s.running = false;
        publish(s);
    }

    private void destroyProcess() {
        if (process == null) return;
        try {
            if (!process.waitFor(2, TimeUnit.SECONDS)) {
                process.destroyForcibly();
                process.waitFor(2, TimeUnit.SECONDS);
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            process = null;
        }
    }

    /** 完全释放（启动器退出时调用） */
    public void shutdown() {
        stop();
        ping.shutdownNow();
        io.shutdownNow();
    }

    private void fail(String message) {
        HostStatus s = copy(latest);
        s.handshaked = true;
        s.running = false;
        s.lastError = message;
        publish(s);
        if (onError != null) onError.accept(message);
    }
}
```

```java
        warn.setWrapText(true);
        warn.getStyleClass().add("settings-card-desc");
        return PageKit.settingsCard("使用说明", "以下限制是架构决定的，无法通过设置绕过。", warn);
    }

    // ---------------------------------------------------------------
    // 状态刷新
    // ---------------------------------------------------------------

    private void tick() {
        // 保底：若 host 进程已死但 UI 还显示运行中，纠正一次
        if (settings.isEnabled() && !manager.isRunning()
                && manager.status().handshaked) {
            applyStatus(manager.status());
        }
        refreshView();
    }

    private void refreshView() {
        boolean running = manager.isRunning();
        enableToggle.setSelected(settings.isEnabled());
        competitiveToggle.setSelected(settings.isCompetitiveMode());

        for (int i = 0; i < qualityButtons.length; i++) {
            if (qualityButtons[i] == null) continue;
            boolean sel = settings.getQuality() == i;
            qualityButtons[i].setStyle(sel
                    ? "-fx-background-color: #3b82f6; -fx-text-fill: white;"
                    : "");
        }
        targetLabel.setText(settings.getTargetFps() + " fps");

        if (!running) {
            backendLabel.setText("未运行");
            captureFpsLabel.setText("—");
            presentFpsLabel.setText("—");
            interpMsLabel.setText("—");
            dropLabel.setText("—");
        }
    }

    private void applyStatus(FrameGenHostManager.HostStatus st) {
        if (st == null) return;

        backendLabel.setText(st.captureBackend.isEmpty() ? "—" : st.captureBackend.toUpperCase());

        // 采样窗口：host 每 500ms 推一次累计帧数，用差分算瞬时 fps
        double captureFps = computeFps(st.captureFrames, true);
        double submitFps  = computeFps(st.presentFrames, false);

        captureFpsLabel.setText(captureFps > 0 ? String.format("%.1f", captureFps) : "—");

        // 呈现 FPS 以「host 实际显示到屏幕的次数」为准，而不是提交次数。
        // 60Hz 屏上提交两次不等于显示两帧，用提交数会虚高。
        if (st.shownFrames > 0) {
            presentFpsLabel.setText(String.valueOf(st.shownFrames));
        } else {
            presentFpsLabel.setText(submitFps > 0 ? String.format("%.1f", submitFps) : "—");
        }

        interpMsLabel.setText(st.interpMs > 0 ? String.format("%.2f ms", st.interpMs) : "—");
        dropLabel.setText(String.valueOf(st.dropFrames));

        if (st.closed || (!st.running && !st.presenting)) {
            backendLabel.setText(st.closed ? "已结束" : "未启动");
        }
    }

    // 简单差分
    private long lastCaptureCount = 0;
    private long lastPresentCount = 0;
    private long lastSampleTimeMs  = 0;

    private double computeFps(long current, boolean capture) {
        long now = System.currentTimeMillis();
        if (lastSampleTimeMs == 0) {
            lastSampleTimeMs = now;
            lastCaptureCount = current;
            lastPresentCount = current;
            return 0;
        }
        long dt = now - lastSampleTimeMs;
        if (dt < 400) {
            return capture ? lastCaptureFps : lastPresentFps;
        }
        long prev = capture ? lastCaptureCount : lastPresentCount;
        double fps = (current - prev) * 1000.0 / dt;

        if (capture) {
            lastCaptureCount = current;
            lastCaptureFps   = fps;
        } else {
            lastPresentCount = current;
            lastPresentFps   = fps;
        }
        lastSampleTimeMs = now;
        return Math.max(0, fps);
    }

    private double lastCaptureFps = 0;
    private double lastPresentFps = 0;

    // ---------------------------------------------------------------
    // 外部入口（由 FrameGenCoordinator 调用）
    // ---------------------------------------------------------------

    /** 游戏启动：若设置允许则自动拉起 host */
    public void onGameStarted(int gamePid) {
        if (!settings.isEnabled() || !settings.isAutoStart()) return;
        if (!FrameGenHostManager.isHostAvailable()) {
            System.err.println("[FrameGen] host 不存在，跳过自动启动");
            return;
        }
        manager.start(gamePid);
        refreshView();
    }

    /** 游戏退出：停止 host */
    public void onGameStopped() {
        if (manager.isRunning()) {
            manager.stop();
        }
        refreshView();
    }

    public FrameGenHostManager manager() { return manager; }

    /** 从启动器其它模块取当前游戏 PID（无则 -1） */
    private int currentGamePid() {
        // 交由 FrameGenCoordinator 注入；此处为默认实现
        try {
            java.lang.reflect.Method m = host.getClass().getMethod("currentGamePid");
            Object v = m.invoke(host);
            return v instanceof Integer ? (Integer) v : -1;
        } catch (Exception e) {
            return -1;
        }
    }
}
```

> **集成提示**：`currentGamePid()` 用反射是过渡方案。正式接入时应在 `LauncherContext` 增加一个 `int currentGamePid()` 默认方法，或由 `FrameGenCoordinator` 在构造 `FrameGenInterpolationPage` 时传入一个 `IntSupplier`。

### 7.2 P1 插值质量

**必须用合成真值序列测，不能只测静止画面。**
静止画面下任何算法（含完全错误的算法）都能轻松通过 PSNR 门限，
上一版文档的「PSNR > 45 dB」实际只验证了像素格式。

合成序列（每段 60 帧，已知中间帧真值）：

| 序列 | 内容 |
|---|---|
| `pan_h` | 纹理单向水平平移 2/4/6/8 px/帧 |
| `pan_v` | 纹理单向垂直平移 2/4/6/8 px/帧 |
| `zoom` | 中心缩放 1.0→1.1 |
| `occlusion` | 前景方块横穿静止背景（测遮挡区） |
| `thinline` | 1px 细线平移（测边缘重影） |
| `checker` | 棋盘格平移（测重复纹理误匹配） |
| `hud_motion` | 静止 HUD 叠加运动背景（测 HUD 是否被插值糊掉） |

| 指标 | 判据 |
|---|---|
| 运动区域 PSNR（`pan_h`/`pan_v`） | ≥ 28 dB，且**优于 blend-only ≥ 3 dB** |
| 垂直/水平增益对称性 | 两个方向增益差 < 2 dB（符号错误时垂直方向会显著变差） |
| 静止区域 PSNR | ≥ 45 dB（回归项，不是质量项） |
| 错误运动矢量比例 | 在 `checker` 上 < 15% |
| 遮挡区伪影 | 不出现「拖尾残影」；允许 1~2 帧的模糊 |
| HUD 区域 | 不出现闪烁；准星允许轻微重影 |
| 插值耗时 | 1080p 下 `interpMs < 8 ms` |
| 输出节奏 | `shownFrames ≈ min(captureFps × 2, displayHz)` |

> **r2 实测基线（合成纹理，Python 参考实现，真值 mv 隔离测试）**
>
> 用真值运动矢量直接喂入两套公式，排除估计器误差后：
>
> | 位移 | r2 公式 | 旧版（符号反） | 纯混合 | r2 增益 | 旧版增益 |
> |---|---|---|---|---|---|
> | (0,6) 水平 | **99.00 dB** | 18.66 dB | 20.72 dB | +78.28 | −2.06 |
> | (6,0) 垂直 | **99.00 dB** | 18.76 dB | 20.69 dB | +78.31 | −1.93 |
> | (−6,0) 反向 | **99.00 dB** | 18.83 dB | 20.79 dB | +78.21 | −1.96 |
> | (0,8) | **99.00 dB** | 18.63 dB | 19.40 dB | +79.60 | −0.77 |
>
> 结论：
> 1. r2 公式在匀速平移下是**数学精确**的（99 dB = 完美重建），水平/垂直增益对称性 0.031 dB。
> 2. 旧版符号错误在任何位移、任何方向上**都比不做 warp 更差**，属负收益。
>
> **但要注意**：上表是「给定正确 mv」的下限验证。实际管线里 mv 由块匹配估计，
> 估计误差会吃掉大部分增益。同一份参考实现在真值 mv 未知时（自估计），
> 水平 6px 只拿到 +0.5 dB、垂直 5px 拿到 +4.46 dB，估计器本身才
> 是当前质量瓶颈（轴向均值 4.67 对真值 6）。
> **因此「增益 ≥ 3 dB」这条门槛同时考察 warp 公式与运动估计，二者缺一不可。**

> **r2 搜索覆盖实测**：步长序列按 `R/2` 递减并在步长 1 上做收敛循环，
> 对 R ∈ {2,4,6,8,12,16} 全部实现 **[-R,R] 内所有轴向偏移 100% 可达**
> （旧三步搜索 R=8 够不到 ±8，R=16 全部奇数偏移不可达）。

### 7.3 P2 稳定性

| 场景 | 判据 |
|---|---|
| 游戏切后台 30 秒 | host 不崩溃，切回后 2 秒内恢复，`rebuildCount` 不异常增长 |
| 拖动窗口连续改变尺寸 | 重建过程中不崩溃、不越界；峰值 GPU 内存可回落 |
| 显示器分辨率改变 | 重建纹理与交换链，画面不撕裂 |
| 拔掉显示器 | host 报 `CAPTURE_LOST` 并退出，游戏不受影响 |
| 启动器强杀 | host 心跳超时（12s）后自杀，不残留进程 |
| 启动器正常退出 | host 收到 `quit` 后 2 秒内退出 |
| 权限不一致（游戏管理员/启动器普通） | host 明确报 `UNSUPPORTED` 并提示，不是静默黑屏 |
| 60Hz 显示器 + 目标 120fps | UI 如实显示钳制为 60Hz，不谎报 120 |

### 7.4 资源与泄漏判定（替代「工作集 < 50 MB」）

工作集受驱动缓存与系统回收影响，短期波动不能证明泄漏，漏也不一定 10 分钟暴露。
必须按资源类型分别观测，并做「只增不减」判定：

| 观测项 | 采集方式 | 判据 |
|---|---|---|
| Private Bytes | `GetProcessMemoryInfo` | 压力循环 20 轮后回落至首轮 ±20% |
| GPU 专用/共享内存 | `IDXGIAdapter3::QueryVideoMemoryInfo` | 停止后回落，不持续阶梯上升 |
| 纹理数量 | 自建计数器（每 Create/Release 记账） | 稳态时恒定 |
| `rebuildCount` | 遥测字段 | 静止场景应恒为 0 |
| 句柄数 | `GetProcessHandleCount` | 20 轮循环后不单调增长 |
| D3D 对象数 | `ID3D11Device::GetCreationFlags` 附近的对象报告 | Release 后归零 |

压测场景：反复启动/停止 20 次、拖动窗口 100 次、切换分辨率 10 次、切后台 20 次。

## 8. 风险与决策记录

### 8.1 已接受的限制

| 限制 | 原因 | 用户可见表现 |
|---|---|---|
| 必须窗口化 | 独占全屏捕获后争抢显示模式 | 页面「使用说明」已声明 |
| 约 1 帧延迟 | 插值固有 | 提供竞技模式直通 |
| 与 Lossless Scaling 冲突 | 同为桌面捕获 | 需加进程检测 |
| 最大 2x | 8x 单帧预算不足 | UI 不提供倍率选择 |
| Win10 可能有黄框 | `IsBorderRequired` 需 Win11 | 文案说明 |
| **需 Win10 1903+** | DXGI 兜底已移除，只走 WGC | 启动时诊断并提示 |
| **输出受刷新率钳制** | 60Hz 屏无法输出 120fps | UI 显示实际节奏 |
| **与游戏同权限层级** | 跨权限 WGC 返回 0x80070005 | 启动时校验并提示 |

### 8.2 待补充（本文未覆盖）

1. **与 Lossless Scaling 的进程冲突检测**：建议在 `FrameGenHostManager.start()` 前用 `ProcessHandle.allProcesses()` 查 `LosslessScaling.exe`，存在则拒绝并 toast。注意进程名可被改名，应提供「我确定要继续」的覆盖入口。
2. **DirectML 神经插值**：`CreateInterpolator` 的 `Quality::Neural` 分支目前降级到 BlockMatch。若 UI 显示 Neural 而实际跑 BlockMatch，必须**在遥测中暴露实际生效档位与降级原因**，否则用户会误判。
3. **HDR 支持**：切 `R16G16B16A16_FLOAT` 只是第一步，还需处理交换链颜色空间、元数据、色调映射与 SDR/HDR 混合，否则仍会偏色。
4. **多显示器**：已改为按目标窗口所在显示器选择（`MonitorIndexForWindow`），但显示器热插拔/断开时的迁移策略未实现。
5. **IPC 身份校验**：当前只 `bind` 回环 + 单连接，本机其它进程仍可发 `stop`。属低危，如需收紧可加启动时随机 token。

### 8.3 明确不做

- ❌ 游戏内注入 / `glfwSwapBuffers` Hook
- ❌ 8x / 6x / 4x 倍率
- ❌ 自研神经网络训练（只用现成 RIFE/IFRNet 权重）
- ❌ 内联到启动器进程（JNI）
- ❌ 支持独占全屏
- ❌ **DXGI Desktop Duplication 兜底**（会把 Presenter 自身捕进去形成反馈环，且遮挡场景内容错误）

### 8.4 性能预算（1080p / 60→120）

| 环节 | 预算 | 实测目标 |
|---|---|---|
| WGC 捕获 | 0.5 ms | 0.3~0.8 ms |
| `CopyResource` ×2 | 0.3 ms | 0.2~0.4 ms |
| 块匹配插值 | 5.0 ms | 3~7 ms |
| 呈现 ×2 | 1.0 ms | 0.5~1.0 ms |
| **合计** | **≤ 8 ms** | — |

超过 8 ms 时 UI 应显示黄色警告并建议降级到「基础」档位。
