#### 关于"一键开服"与私服客户端

本启动器的定位是**客户端启动工具**：功能围绕"把客户端跑起来"展开——版本管理、模组与整合包安装、下载与校验、联机房间、崩溃诊断。

它**不提供**开服向导、服务端配置生成（如 `server.properties`、`eula.txt`）、端口映射、服务器面板或服务器运维功能；也不以"开服"为卖点做分发。

将本软件打包进以营利为目的的"一键开服"整合包、私服客户端、开服面板或代充代练工具，属于**超出本项目用途**的使用，通常伴随：绕过 Mojang 商业授权、售卖游戏本体或账号、未经许可使用 Mod 与整合包作者的资源、面向未成年人收费。

## 五、维护约定

- 本目录文档随版本发布同步更新；修订时递增文档版本号并更新"更新日期"。
- 涉及免责、责任限制、未成年人保护、争议解决的重大修订，应在启动器内弹窗或发布页公告。
- 文档版本与启动器版本解耦：启动器发布新版本不必修改文档，但文档重大修订需在 README 中指向。
- 相关技术文档（下载体系、启动流程等）仍位于本目录其它 `YYYY-MM-DD-*.md` 文件中，与本索引互不冲突。
- **每次修订本目录法律文本后，须重新做一次时间戳存证**：见 [`tools/legal-witness/`](../tools/legal-witness/README.md)，命令为 `-Mode manifest` → `-Mode tsa` → `-Mode record`。

## 六、时间戳存证

本套文档已通过 FreeTSA 取得 **RFC 3161 时间戳**，用于证明"这些规则在建仓/发布之初即已存在"，而非事后补写。

| 项目 | 位置 / 说明 |
|---|---|
| 存证工具与说明 | [tools/legal-witness/README.md](../tools/legal-witness/README.md) |
| 哈希清单 | `tools/legal-witness/MANIFEST-*.sha256`（每次修订生成一份，全部保留） |
| 时间戳令牌 | 同名 `.tsr`（RFC 3161，含 genTime 与 imprint，由 TSA 签名背书） |
| 存证台账 | [WITNESS-LOG.md](../tools/legal-witness/WITNESS-LOG.md)（时间、服务商、编号、哈希） |

**如何自证：** 用 `witness.ps1 -Mode verify` 校验当前文本与最近一份清单是否一致；再计算清单本身的 SHA-256，与 `.tsr` 中记录的 imprint 比对——两者吻合即证明"该文本在该时刻已存在"。具体命令见工具说明。

> 本索引不写死具体哈希值，以免每次存证都触发文本变更、形成"改文本→重新存证→再改文本"的循环；权威哈希一律以 `tools/legal-witness/` 下的清单与台账为准。
