## 1. 背景

当前设置页由 `LauncherView.buildSidebar()` 构建，包含 **6 个分组、20 个导航项、20 个页面、约 90+ 张设置卡片、160+ 个控件**。主要体验问题：

1. **保存模型碎片化**：大量卡片各自带「保存」按钮，用户无法判断是否已保存。
2. **重复设置项多**：窗口、语言、游戏参数、命令、内存等在多页重复出现，容易互相矛盾。
3. **长页面滚动严重**：版本独立设置、高级设置、开发者选项单页过长。
4. **空壳页面与合并价值低**：账户、版权、语言、模组等页面内容过少。
5. **导航项过多**：20 项侧边栏增加查找成本。
6. **危险操作与普通操作混排**：删除、移除、清除缓存等缺少统一隔离。

本重构目标：在不改变配置键与业务功能的前提下，重新规划控件内容、排列与交互，使设置页更易查找、易理解、易保存、少误触。

## 3. 总体设计原则

| 原则 | 说明 |
|---|---|
| 统一保存 | 开关/单选/下拉即时保存；滑杆防抖保存；输入框失焦保存；复杂表单 sticky 保存 |
| 渐进披露 | 低频设置折叠，高频设置默认展开 |
| 单一事实来源 | 同一配置只在一个主页面编辑，其他页面只读或跳转 |
| 就地反馈 | 保存成功用轻提示，不弹窗；失败就地红框 + 文案 |
| 危险隔离 | 删除/移除/清除类操作红色文字 + 二次确认 + 溢出菜单 |
| 可访问性 | 键盘可达、焦点可见、高对比度、色盲辅助实时预览 |
| 性能 | 页面懒加载；不可见时暂停自动刷新；日志监听限流 |

## 4. 全局交互规范

### 4.1 统一保存模型

| 控件类型 | 保存触发 | 反馈 | 异常处理 |
|---|---|---|---|
| CheckBox 开关 | 点击立即保存 | 右下角 Toast「已保存」1.5s | 失败回滚开关 + 错误提示 |
| RadioButton 单选 | 选中立即保存 | 同上 | 同上 |
| ComboBox 下拉 | 选中立即保存 | 同上 | 同上 |
| Slider 滑杆 | 拖动结束 500ms 防抖保存 | 拖动中数值气泡；保存后轻提示 | 越界自动 clamp |
| TextField 单行 | 失焦保存；Enter 保存；Esc 撤销 | 成功轻提示；失败红框 | 校验失败保留输入并提示 |
| TextArea 多行 | 页面底部 sticky 保存条 | 脏标记 + 保存按钮 | 保存失败保留内容 |
| 数字输入框 | 失焦保存 | 越界自动收紧 | 非法字符过滤 |
| 复杂表单 | 底部 sticky 保存条 | 左侧脏标记，右侧保存 | 可「恢复本页默认」 |

**通用要求：**

- 每页右上角提供「恢复本页默认」次要按钮，红色文字，二次确认。
- 全局仅保留 3 处 sticky 保存条：版本独立设置、代理、JVM 参数。
- 保存成功后不刷新整页，仅更新状态与脏标记。
- 切页/切版本时如存在未保存内容，必须弹确认框：`保存并切换 / 放弃修改 / 取消`。

### 4.2 卡片规范

| 项 | 规范 |
|---|---|
| 标题 | 16px 加粗 |
| 副标题 | 12px 次要色，说明影响范围或覆盖关系 |
| 右侧 | 主控件或状态徽标 |
| 同类项 | 合并到一张卡片，用分隔线区分 |
| 卡片间距 | 12px |
| 折叠卡片 | 默认显示一行摘要，点击展开 |
| 危险操作 | 红色文字按钮，优先放入「⋯」菜单 |

### 4.3 状态与反馈

| 状态 | 展示 |
|---|---|
| 已保存 | 轻提示「已保存」 |
| 未保存 | 圆点 +「有 N 项未保存」 |
| 继承全局 | 徽标「继承」 |
| 已覆盖 | 徽标「已覆盖」+ 左侧蓝色竖条 |
| 成功 | 绿色状态点 + 文案 |
| 警告 | 黄色状态点 + 文案 |
| 失败 | 红色状态点 + 文案 + 重试入口 |

### 4.4 危险操作规范

- 删除账号、移除目录、清除下载缓存、恢复默认等必须二次确认。
- 二次确认文案需说明影响范围。
- 危险按钮不放在主操作按钮旁，避免误触。
- 溢出菜单项顺序：打开/查看 → 重命名 → 危险操作。

### 4.5 设置搜索与最近修改

- 侧边栏顶部新增设置搜索框。
- 输入即过滤导航项，并高亮匹配卡片标题。
- 支持搜索配置项名称、页面名称、关键词。
- 侧边栏底部新增「最近修改」，记录最近 5 项，点击直达对应页面并滚动到卡片。

### 4.6 无障碍与键盘

- Tab 顺序按视觉顺序。
- 所有可交互控件有可见焦点环。
- 支持高对比度模式。
- 色盲辅助页提供实时预览。
- 危险确认框默认焦点在「取消」。

### 4.7 性能要求

- 设置页按导航懒加载。
- 下载源健康、本地服务状态等自动刷新在页面不可见时暂停。
- 日志实时监听需限流，避免高频刷新阻塞 UI。
- 折叠卡片内容可延迟构建。

## 6. 页面级需求

### 6.1 游戏账户档案（合并原「账户」）

**涉及文件：** `GameAccountPage.java`、`AccountPage.java`

**目标：** 账户状态与账号列表合并，减少重复入口。

**布局：**

1. 页头：当前账号头像 + 名称 + 类型徽标 + 右侧「+ 添加账号 ▾」。
2. 账号列表：紧凑横向行。
   - 左：头像、名称、类型徽标。
   - 中：非微软账号显示皮肤预览缩略图。
   - 右：当前账号显示绿色竖条 +「使用中」；其他账号显示「切换」+「⋯」。
3. 空状态：居中插画 +「+ 添加账号」大按钮。
4. 「⋯」菜单：皮肤、删除。
5. 底部不再常驻三个登录按钮，统一收进「+ 添加账号 ▾」：微软登录 / 离线登录 / 第三方登录。

**验收：**

- 原 AccountPage 登录状态不再单独成页。
- 账号多时列表可滚动，主按钮不被推出视野。
- 删除账号二次确认。
- 非微软账号可打开 SkinSettingsPanel。

### 6.3 Java 与内存（原 JvmPage）

**涉及文件：** `JvmPage.java`

**目标：** 高频内存设置更顺手，减少保存按钮。

**布局：**

1. 卡片「Java 运行环境」
   - 顶部：自动选择 Java 开关。
   - 路径行：可编辑下拉框 + 搜索 / 浏览 / 检测。
   - 状态行：圆点 + Java 版本与位数。
   - 自动选择开启时，路径行整组置灰。
2. 卡片「内存分配」
   - 显示：`最小 2 GB / 最大 8 GB` + 系统总内存占比条。
   - 快捷档位 chips：2 / 4 / 6 / 8 / 12 GB。
   - 去掉保存按钮，滑杆拖动结束自动保存；最小内存输入框失焦保存。
   - ~~最大/最小内存合并为一条区间滑杆~~（已按上文实现形态修订：最大滑杆 + 最小输入框）
3. 卡片「JVM 参数」
   - 等宽多行文本框。
   - 常用参数速插 chips。
   - 语法校验状态行。
   - 文本变化时显示 sticky 保存条。

**验收：**

- 自动选择 Java 开关位于路径控件上方。
- 内存控件形态为「最大内存滑杆 + 最小内存输入框」，不做双柄区间滑杆。
- 滑杆拖动结束自动保存。
- JVM 参数非法时提示且不阻塞其他设置。

### 6.4 游戏目录（按参考稿重构）

> **2026-10-25 更新：** 本节原描述「当前目录输入卡 + 每项大卡片 + 模组管理折叠卡」的形态已被取代。

**目标：** 还原参考稿的「居中面板 + 4 行定高单选列表 + 详情/添加视图」排版与动画；

**布局：**

1. 面板头：标题 + 胶囊搜索（收起 32px，点击展开 220px，失焦且为空时收起）+「+ 添加目录」。
2. 当前路径摘要栏：只读显示当前 `GameDir`，长路径省略 + Tooltip。
3. 列表：固定 4 行高（284px）内部滚动；行内容 = 单选圆点 + 名称 + 路径/版本数 +「当前使用」徽标 +
   悬停操作（重命名 / 打开 / 移除）；最后一行不画分隔线。
4. 详情视图（双击行）：图标 + 名称 + 使用状态徽标；「存放路径」卡；

7. 不再包含「当前游戏目录」输入卡与「模组管理」折叠卡；模组管理的正式入口需另行安排
   （`HomeQuickManageMod` 配置键仍保留，当前没有页面控件写入）。

**交互与动画：**

- 单击行 = 设为当前目录（就地刷新选中态，不重挂页面）；双击 = 打开详情。
- 动画：面板入场、列表逐条入场、选中竖条/圆点/徽标回弹、悬停操作淡入、
  视图高度 400ms 过渡、详情/添加淡入、删除退场、新增高亮、按钮按压缩放。
- 颜色走启动器主题（light / dark / high-contrast），不硬编码参考稿的浅色；
  高对比度下使用纯黑/纯白边框与文字。

**验收：**

- 与参考稿的尺寸、层级、控件顺序一致；深色与高对比度下仍可读。
- 切换当前目录后列表/摘要即时更新，版本选择页、资源页、首页缓存同步刷新。
- 添加/重命名/移除后不重挂整页，列表与搜索状态就地更新。
- 移除目录二次确认；至少保留一个目录。

### 6.6 高级设置（原 AdvancedPage）

**涉及文件：** `AdvancedPage.java`

**目标：** 去重 + 分区折叠，明确全局默认与版本覆盖关系。

**去重要求：**

| 重复项 | 决策 |
|---|---|
| 窗口大小 / 全屏 | 只留高级设置，标注可被版本独立设置覆盖 |
| 游戏语言 / 版本隔离 / 游戏参数 / 启动前命令 / 退出后命令 | 只留高级设置作为全局默认 |
| 内存优化 | 移到 JvmPage 内存卡片 |
| 主题相关 | 全部归 ThemePage |

**新布局分区：**

1. 启动选项：使用高性能显卡、JVM 预热启动。
2. 窗口：宽 × 高、全屏、自定义标题、进程优先级、启动器可见性。
3. 游戏默认值：游戏语言、版本隔离、游戏参数、启动前命令、退出后命令。
4. 性能与校验：并行资源准备、并行文件校验、流式哈希校验、快速校验、校验状态缓存。
5. 社区资源：文件名格式、Mod 管理样式、忽略 Quilt。
6. 登录：静默登录时机。
7. AI 配置：服务商 chip 墙 → API 地址 → API Key → 模型 → 状态提示。

**验收：**

- 不再出现跨页同名设置。
- 默认仅展开「启动选项」「窗口」。
- AI 配置纵向一步一行，不拥挤。

## 7. 组件与接口需求

| 组件/服务 | 职责 |
|---|---|
| `SettingCard` | 统一卡片标题、副标题、右侧控件、折叠 |
| `StickyActionBar` | 底部保存条、脏标记、恢复默认 |
| `SaveCoordinator` | 统一保存模型、防抖、失败回滚 |
| `DirtyTracker` | 页面脏状态跟踪 |
| `ToastService` | 轻提示 |
| `DangerConfirmDialog` | 危险操作二次确认 |
| `SettingsSearchService` | 设置搜索、最近修改 |
| `CollapsibleSection` | 分区折叠与状态持久化 |
| `NavRouter` | 新旧导航 ID 映射、深链兼容 |

> **导航数据源约定（评审结论）：** 新 IA 的分组 / 顺序 / 命名 / 深链映射以 **单一数据源**
> 维护（`PageKit.SETTINGS_NAV_ITEMS`，含 NavRouter 重定向标记），侧边栏
> （`LauncherView.buildSidebar()`）与顶部下拉导航（`PageKit`）都从该数据源渲染，
> 禁止两处各写一份清单导致漂移。页内跳转（如辅助功能页「详细配置」→ 色盲子页）
> 也必须走 NavRouter，不能直接硬编码 `switchToSettings("sidebarColorBlind")`——
> 该 id 已不在侧边栏显示，但作为内部路由目标必须继续可达。

## 8. 配置与兼容要求

- 不修改现有配置键。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 统一保存模型影响面大 | 先做 `SaveCoordinator`，按页面灰度迁移 |
| 合并页面破坏深链 | 保留旧 ID 映射与重定向 |
| 自动保存与手动保存冲突 | 复杂表单统一 sticky，禁止混用 |
| 折叠状态导致找不到设置 | 搜索 + 最近修改 + 默认展开高频分区 |
| 日志实时监听性能问题 | 限流、不可见暂停、日志区缩小 |
