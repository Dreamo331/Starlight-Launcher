# 星光启动器 Starlight Launcher · 隐私政策

**版本 1.0 · 更新日期：2026 年 10 月 20 日 · 生效日期：2026 年 10 月 20 日**

> 本政策说明星光启动器（以下称"本软件"或"本启动器"）如何处理与你的隐私相关的信息。**我们尽量只用一句话说明一件事，并用表格列出"数据是否离开你的设备"。**
>
> 本政策是[用户服务协议](用户服务协议.md)的组成部分。请一并阅读[免责声明](免责声明.md)与[第三方声明](第三方声明-Third-Party-Notices.md)。

## 一、核心承诺

1. **本启动器作为本地工具，高度尊重用户隐私。我们不收集、不存储你的任何真实身份信息、支付密码或银行卡信息。**
2. **本软件自身不包含任何内建的充值、支付或打赏系统。** 如你在游玩中遇到需要付费的环节，那必然发生在第三方服务器内或第三方网站上，请仔细甄别。
3. **本软件无广告 SDK、无行为追踪 SDK、无设备指纹采集。** 我们不使用任何第三方统计平台记录你的使用行为。
4. **日志上传仅在你主动点击时发生**，不存在后台自动上报；上传后的链接与二维码会记录在"日志记录"页，你可随时撤回删除。
5. **软件仅在本地读取必要的游戏配置与目录以完成启动功能，不将你的本地文件上传至任何未经授权的第三方服务器。**

**一句话概括：我们不建用户画像、不卖数据、不投放广告。你的数据主要留在你自己的电脑上。**

## 二、适用范围

2.1 **适用。** 本政策适用于本软件本体（含安装包、便携版、单文件 EXE）、其内建页面、更新通道、插件 API 服务、社区模块与日志上传功能。

2.2 **不适用。** 本政策不适用于下列第三方主体的处理行为，请查阅其各自的隐私政策：

- Mojang / Microsoft（游戏账号登录、游戏文件分发）；
- 你连接的第三方游戏服务器；
- 皮肤站（如 LittleSkin）、authlib-injector 生态内的认证服务；
- Modrinth、CurseForge、mcmod.cn、下载镜像站（BMCLAPI 等）；
- 日志分享服务（Logshare）；
- 你自行配置的 AI 服务商；
- 你自行安装的插件及其作者提供的服务。

## 三、数据分类与处理清单

### 3.1 仅保存在本机、不上传的数据

| 数据 | 位置（默认） | 用途 |
|---|---|---|
| 启动器设置、窗口状态、主题、壁纸路径 | `~/.starlight/starlight.ini` 等 | 记住你的偏好 |
| 账号列表、显示名、UUID、头像缓存 | `~/.starlight/accounts.json`、`avatars/` | 免登录切换账号 |
| 登录令牌 `accessToken` / `refreshToken` | 同上（明文或轻量混淆） | 免密登录与令牌刷新 |
| 已下载的 Java 运行时、联机组件、插件 | `~/.starlight/java/`、`plugins/` 等 | 提供功能 |
| 日志文件、崩溃报告 | 工作目录 `logs/`；游戏目录 | 供你自行排查 |
| 收藏、下载记录、版本隔离配置 | 本机配置目录与 `.minecraft` | 提供功能 |

> 以上数据**不会**被本软件自动上传。你可以随时删除 `~/.starlight/` 与工作目录下的 `logs/` 来清除它们。

### 3.2 需要访问但不上传的数据

| 数据 | 读取目的 |
|---|---|
| `.minecraft` 游戏目录（版本、模组、存档、设置、日志） | 启动游戏、管理资源、崩溃诊断 |
| 系统内存、CPU、Java 版本等**运行时信息** | 推荐合适的 JVM 参数、诊断启动失败 |
| 你输入的服务器地址、皮肤站地址 | 建立连接、获取皮肤 |

上述信息在本地处理，**除下述 3.3 情形外不会离开你的设备**。

### 3.3 会发送到外部服务的数据（你知情或主动触发）

| 场景 | 发送内容 | 接收方 | 触发方式 |
|---|---|---|---|
| 登录微软账号 | 微软账号授权流程所需的 OAuth 数据 | `login.microsoftonline.com`、`xboxlive.com`、`api.minecraftservices.com` | 你点击登录 |
| 外置登录 / 皮肤站 | 用户名、密码或令牌（按该站协议） | 你选择的皮肤站 | 你点击登录 |
| 下载游戏与模组 | 请求的版本、模组 ID；你的 IP 与 User-Agent | Mojang、BMCLAPI 等镜像、Modrinth、CurseForge、各 Maven 仓库 | 你点击下载 |
| 检查更新 | 当前版本号；你的 IP 与 User-Agent | 官方更新接口 / GitHub / Gitee | 自动（可关闭） |
| 日志上传 | 日志文件内容（含本机路径、系统信息、游戏报错） | Logshare 等日志分享服务 | **仅你主动点击"上传日志"** |
| 联机（SLan / Terracotta / FRP） | 房间信息、你的公网 IP 或中继分配地址 | 你选择的中继服务器、房间成员 | 你点击创建/加入房间 |
| 社区模块 | 社区账号信息、帖子与评论内容 | 第三方社区站点 API | 你主动登录并发帖 |
| AI 助手 | 你输入的提示词与相关上下文 | **你自行选择的** AI 服务商 | 你主动发送 |
| 插件 API | 由插件发起的请求（限定在你授予的 API 范围内） | **仅本机** `127.0.0.1` | 插件运行时 |

**关于日志上传的特别提示：** 日志中可能包含你的 Windows 用户名、文件路径、服务器地址、模组列表与报错堆栈。**上传前请自行确认内容是否包含敏感信息**；上传成功后你可在"日志记录"中**随时撤回删除**该日志。

## 四、我们不会收集的信息

在正常使用范围内，本软件**不会**收集、请求或上传下列信息：

- 真实姓名、身份证号、手机号、住址等身份信息；
- 支付密码、银行卡号、支付账户与验证码；
- 通讯录、短信、通话记录、相册、麦克风、摄像头、剪贴板内容；
- 精确定位；
- 生物识别信息；
- 你在本软件之外的浏览历史与行为轨迹。

> 说明：插件可能通过启动器 API 读取本机信息（如账号列表、游戏设置）。**插件的行为由插件作者负责**，请只安装来源可信的插件，并在安装前了解其权限。本软件默认仅允许插件访问其声明的接口，且 API 服务仅绑定本机回环地址 `127.0.0.1`，局域网内其他设备无法访问。

## 五、Cookie、追踪与广告

5.1 本软件为桌面程序，**不使用浏览器 Cookie**。

5.2 本软件**不集成**第三方广告 SDK、行为分析 SDK、崩溃自动上报 SDK 或设备指纹技术。

5.3 本软件界面中的第三方内容（如模组介绍、社区帖子、外部链接）由第三方提供，其页面可能含有该第三方的追踪脚本，适用该第三方的隐私政策。

5.4 若未来引入任何统计或崩溃收集功能，我们将在本政策中明确说明其范围、接收方与关闭方式，并提供**默认关闭**的选项，不会静默开启。

## 六、未成年人隐私

6.1 本软件不面向未成年人主动收集个人信息，也不建立用户画像。

6.2 **未满 18 周岁的用户请在监护人指导下使用本软件。** 监护人应特别注意：不要在第三方服务器内进行未经同意的支付（见[免责声明](免责声明.md)第三条）。

6.3 监护人如发现未成年人向第三方服务器进行了消费，请**直接向服务器运营方或支付机构**主张权利；本软件既非收款方，也未存储任何支付信息，客观上无法代为退款。

## 七、数据安全

7.1 **存储位置。** 你的数据默认保存在本机 `~/.starlight/`（便携模式为工作目录下的 `Starlight-Launcher/`）。我们**没有**用于存储用户数据的中央服务器。

7.2 **风险提示。** 账号令牌以明文或轻量混淆形式保存在本机，**这与多数开源启动器的做法一致**，但意味着：能访问你电脑文件的人，也可能读取到令牌。请勿在公用或不受信任的电脑上保存账号，并保持系统登录密码与磁盘加密。

7.3 **删除即删除。** 卸载本软件或删除 `~/.starlight/` 后，本机数据即被移除；我们不存在需要另外申请删除的服务端副本。

7.4 **安全事件。** 若发生涉及用户数据的安全事件，我们将在发布页公告，并说明影响范围与处置建议。

## 九、你的权利

9.1 **访问与知悉：** 本政策已列明数据类别与去向；你也可直接查看 `~/.starlight/` 下的文件。

9.2 **更正与删除：** 你可在"设置"中清除配置，或直接删除 `~/.starlight/`、`logs/`、账号条目与上传记录。

9.3 **撤回同意：** 你可随时关闭自动检查更新、退出社区模块、移除皮肤站账号、不再上传日志。

9.4 **注销：** 本软件**没有中心化账号体系**，因此不存在"注销启动器账号"的操作；删除本地数据即可完成清除。

9.5 **投诉与咨询：** 通过官方仓库 Issues 或 README 公布的联络渠道反馈，我们将在合理期限内答复。

## 附录 · 本机数据目录速查

| 路径 | 内容 | 可否直接删除 |
|---|---|---|
| `~/.starlight/` | 配置、账号、Java、插件、皮肤、壁纸、联机组件 | 可（会重置全部设置与账号） |
| `logs/`（工作目录） | 启动日志、崩溃日志 | 可 |
| `.minecraft/` | 游戏本体、模组、存档 | 不可随意删除，会丢失游戏与存档 |
| 游戏目录内 `.cache/` | 文件校验状态 | 可（会触发重新校验） |

> 删除前请确认路径，**误删 `.minecraft/` 会导致存档永久丢失**，请先备份。
