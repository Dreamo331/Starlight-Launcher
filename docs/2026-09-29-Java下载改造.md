# Java 下载改造：符合 jdk-install 文档（关键 LTS 索引 + 多源）

日期：2026-09-29
需求来源：`temp/jdk-install.md`（Minecraft 启动器 Java 下载索引描述）+ `src/main/resources/assets/jdk-install.json`

## 目标

按文档把启动器的 Java 下载从"硬编码 3 个固定版本 + 固定 URL"改为"索引驱动 + 关键 LTS 版本 + 多镜像源"，且版本永不因官方发新版而过时。

## 改动清单

### 1. `src/main/resources/assets/jdk-install.json`（重写为标准索引结构）

- 采用文档 §4 的 `minecraft-java-downloads.json` 结构（schema_version / name / recommended_strategy / last_updated / sources / versions）。
- 修复原文件两处模板错误：
  - `8u{update}_b{ build}` 占位符带空格且连字符错误（Adoptium 8 系真实命名是 `8u{update}b{build}`，如 `8u482b08`）——由于改为目录式解析，模板已整体替换；
  - 11/17/21/25 写成 `.tar.gz` 固定后缀，而 Windows 清华镜像实际是 `.zip`。
- 只维护 5 个关键 LTS 版本：8 / 11 / 17 / 21 / 25，并标注每个版本的 Minecraft 支持范围（对齐文档映射表）：
  - 8  → 1.12.2 及以下
  - 11 → 1.13 - 1.16.5
  - 17 → 1.17 - 1.20.4
  - 21 → 1.20.5 及以上
  - 25 → 未来版本预留

### 2. `src/main/java/com/example/starlight/installjava/JavaInstall.java`（核心重写，v4.0）

- **索引驱动**：启动时读取内嵌资源 `/assets/jdk-install.json`（`Class.getResourceAsStream`），不再硬编码版本列表；新增版本自动随索引扩展。
- **版本支持**：`jdk8|8`、`jdk11|11`、`jdk17|17`、`jdk21|21`、`jdk25|25`（原仅 8/17/21）。
- **多镜像源（按顺序尝试，失败自动切换）**：
  1. **清华 TUNA 镜像**（国内加速优先）：解析 `https://mirrors.tuna.tsinghua.edu.cn/Adoptium/{ver}/jdk/{arch}/{os}/` 目录列表，正则抓取 `OpenJDK{U}-jdk_{arch}_{os}_hotspot_*.zip`，**按版本号数值元组（major.minor.update.patch.build）排序取最新**（修复字典序把 17.0.9 排在 17.0.10 之后的缺陷）；带完整浏览器请求头降低被镜像站 WAF 拦截概率。
  2. **Adoptium 官方 API 直链**：`binary/latest/{ver}/ga/{os}/{arch}/jdk/hotspot/normal/eclipse`，302 自动重定向到最新 GA 安装包，永不过时。
  3. **Amazon Corretto 官方 latest 直链**（Windows x64 兜底，文档备选源之一）：8/11/17/21/25 五个版本均验证有效（HEAD 200）。
  - 说明：文档中"华为云镜像"经实测仓库只存 Oracle OpenJDK（`openjdk/` 目录 2021 年后基本停更），且文档明确"不建议集成 Oracle JDK"，故未采用华为路径。
- **系统识别**：自动检测 os（windows/linux/mac）与 arch（x64/aarch64/x86），对照索引的 os_options / arch_options 校验，非支持平台明确报错。
- **输出与内嵌模式保持兼容**：`--json` 行格式、`setOutput(PrintStream)` 注入、`starlight.embed` 系统属性失败抛异常（不杀宿主 JVM）均保留，`JavaEnvironmentManager`/`JavaService`/`UIGeneralControlClass` 的进度解析无需改动。

### 3. `src/main/java/com/example/starlight/service/JavaEnvironmentManager.java`

- `jdkNameForMajor`：从 3 档（8/17/21）扩为 5 档（8/11/17/21/25），与索引一致：
  `<=8→jdk8；<=11→jdk11；<=17→jdk17；<=21→jdk21；else→jdk25`
- 启动链路 `ensureJavaForLaunch` 自动按游戏版本下载对应 JDK 的逻辑不变（缺 Java 自动装、装好写配置 + 配环境变量）。

### 4. `src/main/java/com/example/starlight/gui/UIGeneralControlClass.java`

- `getRequiredJavaMajor` 映射对齐文档（原 1.13-1.16.5 判 8、1.17-1.17.x 判 16）：
  - `>=26.1 → 25`；`>=1.20.5 → 21`；`>=1.17 → 17`；`>=1.13 → 11`；其余 → 8
- `getAvailableJdkVersions`：`jdk8/jdk11/jdk17/jdk21/jdk25`。

### 5. `src/main/java/com/example/starlight/newui/page/settings/JvmPage.java`

- 「自动安装」按钮旁新增**版本下拉**（8 / 11 / 17 / 21 / 25，默认 17），不再硬编码 jdk17；「下载 Java」按钮仍打开 Adoptium 官网下载页（`JDK_DOWNLOAD_PAGE`）。

### 6. 其他同步

- `src/main/java/com/example/starlight/service/JavaService.java`：`getAvailableJdkVersions` 5 版本。
- `src/main/java/com/example/starlight/main/CliHandler.java`：`installjava` 帮助文本更新。
- `src/main/java/com/example/starlight/pluginapi/provider/JavaInstallApiProvider.java`：Query 参数注释更新。
